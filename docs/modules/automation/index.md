# Workflow və avtomatlaşdırma

Workflow təriflərini, kataloqu və toplu əməliyyatları idarə edir.

## Modulun sərhədi

Definition özü nəticə yaratmır; run və bulk action seçilən resursda dəyişiklik edə bilər.

## Tipik iş axını

Kataloqdan trigger/action seçin, workflow yaradın, run nəticələrini izləyin və uğursuz run-u retry edin.

## Sistem təsiri

Seçilən action-dan asılıdır; hər run status və nəticə tarixçəsi saxlayır.
