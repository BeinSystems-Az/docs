# Hesabatlar

ERP üzrə mövcud hesabat kataloqunu və filter-lənmiş hesabat nəticələrini təqdim edir.

## Modulun sərhədi

Hesabat endpointləri mənbə əməliyyat məlumatını oxuyur; biznes sənədini və ya jurnal nəticəsini dəyişmir.

## Tipik iş axını

Əvvəl kataloqdan report key və filter kontraktını alın, sonra həmin key ilə hesabatı icra edin.

## Sistem təsiri

Yoxdur; yalnız hesablanmış oxu nəticəsi qaytarılır.
