# Modullar

| Modul | Məsuliyyət |
| --- | --- |
| Core / Metadata | Dataset, field, view schema, layout və dinamik UI metadata. |
| Auth | İstifadəçi, rol, permission və authorization audit. |
| Partner | Müştəri, təchizatçı və tərəfdaş əsas məlumatları. |
| Product / Inventory | Məhsul, vahid, qiymət və inventar master data. |
| Sales / Purchase | Satış və alış sənədləri, status keçidləri. |
| Stock | Anbar qalıqları, transfer, rezervasiya və hərəkətlər. |
| Accounting | Hesablar, jurnal, posting və maliyyə hesabatları. |
| HR | İşçi və təşkilati struktur. |
| POS | POS aktivasiya, sync, satış və növbə əməliyyatları. |
| Manufacturing | BOM, routing və istehsal sifarişləri. |
| Reports / Output | Hesabat kataloqu və sənəd çıxışları. |
| AI / Integrations | AI action-lar və service-account inteqrasiyaları. |

Modullar arası maliyyə və stok təsirləri domain service-lər vasitəsilə idarə olunur. Yeni modul mövcud tenant, authorization və API response qaydalarına əməl etməlidir.
