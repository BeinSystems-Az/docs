# Tərəfdaşlar

Müştəri, təchizatçı, tərəfdaş qrupu, bank hesabı və vergi ödəyicisi yoxlamalarını idarə edir.

## Modulun sərhədi

Tərəfdaş master məlumatdır; özü satış, alış, borc və jurnal yaratmır.

## Tipik iş axını

Qrup və tərəfdaşı yaradın, rekvizit və bank hesablarını tamamlayın, sonra biznes sənədlərində istifadə edin.

## Sistem təsiri

Dəyişiklik gələcək sənədlərdə seçimi və rekvizitləri dəyişir; post edilmiş sənəd snapshot-larını dəyişmir.
