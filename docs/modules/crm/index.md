# CRM

Bu modulun API resursları aşağıdadır. Endpoint kontraktı üçün resurs səhifəsini açın.

## Resurslar

| Resurs | Nə üçün istifadə olunur |
| --- | --- |
| [CRM icmalı](./resources/dashboard) | CRM icmalı məlumat və əməliyyatlarını idarə edir. |
| [CRM mənbələri](./resources/source) | CRM mənbələri məlumat və əməliyyatlarını idarə edir. |
| [CRM mərhələləri](./resources/stage) | Pipeline daxilində lead-in cari mərhələsini və ardıcıllığını müəyyən edir. |
| [CRM pipeline-ları](./resources/pipeline) | Lead-lərin keçdiyi satış prosesinin pipeline təriflərini saxlayır. |
| [CRM tapşırıqları](./resources/task) | Lead ilə bağlı zəng, görüş və digər izləmə tapşırıqlarını saxlayır. |
| [İtirmə səbəbləri](./resources/lost-reason) | İtirmə səbəbləri məlumat və əməliyyatlarını idarə edir. |
| [Lead-lər](./resources/lead) | Potensial satış imkanını, gözlənən gəliri, ehtimalı, məsul şəxsi və pipeline mərhələsini saxlayır. |
