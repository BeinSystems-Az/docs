# Çıxış və çap

Sənəd output-u, HTML/çap görünüşü və output template-lərini idarə edir.

## Modulun sərhədi

Çıxış mövcud sənədi render edir; biznes sənədinin state və məbləğini dəyişmir.

## Tipik iş axını

Template-i qurun, sənəd üçün output preview/render tələb edin və nəticəni çap və ya ixrac edin.

## Sistem təsiri

Yoxdur; yalnız təqdimat nəticəsi yaradır.
