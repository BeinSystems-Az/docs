# Biznes şəbəkəsi

Tenant-lərarası əlaqə, mapping və sənəd mübadiləsini idarə edir.

## Modulun sərhədi

Şəbəkə qəbul və göndəriş qatıdır; yerli biznes sənədi yalnız import/accept əməliyyatında yaranır.

## Tipik iş axını

Profili tapın, əlaqə yaradın, mapping-ləri qurun, exchange göndərin və qarşı tərəfdə qəbul və ya rədd edin.

## Sistem təsiri

Qəbul edilən exchange yerli sənəd yarada bilər; rədd yalnız mübadilə state-ni dəyişir.
