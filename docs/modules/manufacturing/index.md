# İstehsal

BOM, routing, iş mərkəzi və istehsal sifarişinin materialdan hazır məhsula axınını idarə edir.

## Modulun sərhədi

Master məlumatlar stok yaratmır; istehsal sifarişinin lifecycle action-ları material sərfi və hazır məhsul qəbuluna səbəb olur.

## Tipik iş axını

BOM və routing qurun, production order yaradın, təsdiqləyin, başladın, istehlakı qeyd edin və tamamlayın.

## Sistem təsiri

İstehsalın icrası material stokunu azaldır, hazır məhsulu artırır və valuation nəticəsi yarada bilər.
