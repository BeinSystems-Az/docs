# Partiya və seriya nömrələrini idarə etmək

Partiya və seriya nömrəsi məhsulu alınma/istehsal qrupu və ya ayrı-ayrı vahid üzrə izləməyə imkan verir. Bu qeydlər özləri stok yaratmır; müvafiq məhsul üçün stok izləmə aktiv olduqda anbar sənədində istifadə olunur.

## İstifadə qaydası

### Məhsulda izləmə üsulunu aktiv edin

1. Məhsul kartını açın. **Anbar** hissəsində izləmə tələb olunan məhsul üçün partiya/seriya izləmə seçimini aktiv edin və kartı yadda saxlayın.

   > **Şəkil əlavə ediləcək —** `media/user-guide/catalog/traceability/images/screen-01.png`: Məhsul kartında izləmə seçimi və anbar bölməsi.

### Lot və ya seriya kartı yaradın

2. **Məhsul → Partiyalar və seriyalar** səhifəsini açıb **Yeni** seçin.

3. **Məhsul** seçin və **Lot / seriya nömrəsi** sahəsini doldurun. Partiya qeydi yaradırsınızsa **Aid olduğu partiya** sahəsini boş saxlayın. Məhsul həm partiya, həm seriya ilə izlənirsə seriya qeydi üçün uyğun partiyanı seçin.

4. Məhsulun son istifadə tarixi varsa **Son istifadə tarixi** daxil edin. Qeydi yadda saxlayın və məhsula bağlı siyahıda göründüyünü yoxlayın.

   > **Şəkil əlavə ediləcək —** `media/user-guide/catalog/traceability/images/screen-02.png`: Məhsul, lot/seriya nömrəsi, aid olduğu partiya və son istifadə tarixi sahələri.

### Stok sənədində istifadə edin

5. Alış, istehsal və ya uyğun anbar sənədinin məhsul sətrində həmin məhsul/partiya/seriyanı seçin. Miqdarı real hərəkətə uyğun daxil edin.

6. Sənədi təsdiqləməzdən əvvəl məhsul və izləmə nömrəsinin uyğun olduğunu yoxlayın. Sonra məhsul üzrə partiya tarixçəsi və anbar qalığını izləyin.

   > **Video əlavə ediləcək —** `media/user-guide/catalog/traceability/videos/walkthrough-01.mp4`: Məhsulda izləməni aktiv etmək, partiya/seriya kartı açmaq və alış sənədində seçmək.

## Lüğət

| Termin | Bu səhifədəki mənası |
| --- | --- |
| Lot/partiya | Eyni istehsal və ya qəbul partiyasına aid məhsul qrupunu müəyyən edən nömrədir. |
| Seriya nömrəsi | Məhsulun ayrı-ayrı fiziki vahidini identifikasiya edən unikal nömrədir. |
| Aid olduğu partiya | Seriya nömrəsini üst partiyaya bağlayır; yalnız seriya ayrıca izlənmirsə boş qala bilər. |
| Son istifadə tarixi | Partiya/seriyanın istifadə oluna biləcəyi son təqvim tarixidir. |

## FAQ

### Partiya yaratmaq anbarda həmin məhsuldan miqdar yaradırmı?

Xeyr. Partiya kartı izləmə identifikatorudur. Faktiki miqdar alış, istehsal və stok sənədləri ilə qeydə alınır.

### Hər məhsulda seriya nömrəsi olmalıdır?

Yalnız seriya ilə izləmə tələb olunan məhsullarda. Məhsul kartının izləmə parametrini iş prosedurunuza uyğun qurun.

### Son istifadə tarixinə saat daxil etməliyəm?

Xeyr. Sistem göstərilən son istifadə gününün sonunadək istifadəyə icazə verir; saat nəzərə alınmır.
