# Məhsul kateqoriyası yaratmaq

Kateqoriyalar məhsul siyahısını qruplaşdırır və kataloqda axtarışı asanlaşdırır. Kateqoriya yaratmaq özü məhsul, stok qalığı və ya maliyyə yazılışı yaratmır.

## İstifadə qaydası

### Kateqoriya siyahısını açın

1. Sol menyudan **Məhsul → Kateqoriyalar** bölməsinə keçin.

   > **Şəkil əlavə ediləcək —** `media/user-guide/catalog/categories/images/screen-01.png`: Sol menyuda Kateqoriyalar seçimi və kateqoriyaların ad/hierarxiya sütunları görünən siyahı.

2. Siyahının yuxarısındakı **Yeni** düyməsini seçin.

### Kateqoriyanın adını və üst kateqoriyasını təyin edin

3. **Ad** sahəsini doldurun. Bu məcburi addır və məhsul kartında kateqoriya seçərkən görünür.

4. Kateqoriyanı başqa kateqoriyanın daxilində saxlamaq istəyirsinizsə, **Üst kateqoriya** sahəsindən onu seçin. Əsas kateqoriya yaradarkən bu sahəni boş saxlayın.

   > **Şəkil əlavə ediləcək —** `media/user-guide/catalog/categories/images/screen-02.png`: Kateqoriya formasında Ad və Üst kateqoriya sahələri, bir alt kateqoriya nümunəsi.

5. Kateqoriyadan istifadə olunmasını dayandırmaq istəyirsinizsə **Aktiv** seçimini söndürün. Mövcud məhsullarla əlaqələrin nəticəsini nəzərə almadan kateqoriyanı silməyin; əvvəlcə əlaqəli məhsulları yoxlayın.

### Yadda saxlayın və məhsula bağlayın

6. **Yadda saxla** düyməsini seçin. Kateqoriyanın siyahıda göründüyünü yoxlayın.

7. Kateqoriyanı məhsula tətbiq etmək üçün məhsul kartını açın və **Ümumi** hissəsindəki **Kateqoriya** sahəsindən onu seçin.

## Lüğət

| Termin | Bu səhifədəki mənası |
| --- | --- |
| Kateqoriya | Məhsul kartlarını kataloqda qruplaşdırmaq üçün istifadə olunan təsnifatdır. |
| Üst kateqoriya | Cari kateqoriyanı daha geniş kateqoriyanın daxilində yerləşdirərək ağac quruluşu yaradır. |
| Aktiv kateqoriya | Məhsul seçimi zamanı istifadə oluna bilən kateqoriyadır. |

## FAQ

### Məhsul yaratmaq üçün kateqoriya mütləqdirmi?

Xeyr. Kateqoriya məhsulları qruplaşdırmaq üçündür; məhsul kartında məcburi deyil.

### Kateqoriyaları iç-içə yaratmaq olar?

Bəli. Alt kateqoriya yaradarkən **Üst kateqoriya** sahəsində mövcud kateqoriyanı seçin.

### Kateqoriyanı deaktiv etsəm məhsullar silinər?

Kateqoriyanı deaktiv etmək məhsul kartlarını silmək əməliyyatı deyil. Deaktiv kateqoriyanın seçimdə görünməsi icazə və ekran qaydalarından asılı ola bilər; əlaqəli məhsulları ayrıca yoxlayın.
