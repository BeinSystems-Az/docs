# Ölçü vahidi yaratmaq

Ölçü vahidi məhsul miqdarını ifadə edir. Məhsul kartında istifadə edilməzdən əvvəl vahidin adı, yuvarlaqlaşdırma dəqiqliyi və varsa referens vahidlə çevirməsi qurulur.

## İstifadə qaydası

1. **Ayarlar → Məhsul → Ölçü vahidləri** səhifəsini açıb **Yeni** seçin.
2. Məcburi **Məhsul Ölçü Vahidi** sahəsinə vahidin adını yazın.
3. Vahid başqa vahidə çevrilirsə **Referens vahid** və **Tərkib miqdarı** daxil edin. Əsas vahiddirsə uyğun referens seçməyin.
4. Məcburi **Yuvarlaqlaşdırma dəqiqliyi**ni məhsul ölçüsünə uyğun göstərin. Lazımdırsa **Sıra**nı dəyişin.
5. Vahidi yadda saxlayıb məhsul kartında seçilə bildiyini yoxlayın. **Mütləq əmsal** sistem tərəfindən hesablanır.

   > **Şəkil əlavə ediləcək —** `media/user-guide/catalog/units-packaging/images/screen-01.png`: Vahid adı, referens çevirmə əmsalı və dəqiqlik.

## Lüğət

| Termin | Bu səhifədəki mənası |
| --- | --- |
| Referens vahid | Yeni vahidin çevirmə əlaqəsi qurduğu mövcud vahiddir. |
| Tərkib miqdarı | Bir referens vahiddə neçə vahid olduğunu göstərir. |
| Mütləq əmsal | Vahid çevirməsi üçün sistemin hesabladığı dəyərdir. |
| Yuvarlaqlaşdırma dəqiqliyi | Miqdarın hesablanıb göstəriləcəyi onluq mərtəbədir. |

## FAQ

### Vahidin adı və dəqiqliyi məcburidir?

Bəli. **Məhsul Ölçü Vahidi** və **Yuvarlaqlaşdırma dəqiqliyi** tələb olunur.

### Qablaşdırmanı haradan yaradıram?

Bu menyu səhifəsi vahid çevirmə üçündür. Məhsul qablaşdırması ayrıca səhifə və ya məhsul kartı sahəsi kimi təqdim olunursa, məhsul təlimatına baxın.
