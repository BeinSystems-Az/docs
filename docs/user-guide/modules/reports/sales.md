# Satış hesabatını təhlil etmək

**Hesabatlar → Satış** səhifəsi satış göstəricilərini seçilmiş dövr və ölçülər üzrə təhlil edir. Müştəri hesablaşması və stok hərəkətini dəqiqləşdirmək üçün ilkin satış sənədinə keçin.

## İstifadə qaydası

1. **Hesabatlar → Satış** səhifəsini açın.
2. Dövr və ekranda təklif olunan filial, müştəri, məhsul və status filtrlərini seçin.
3. Hesabatı yeniləyin, ümumi satış və detallaşdırılmış nəticələri müqayisə edin.
4. Konkret nəticəni araşdırmaq üçün əlaqəli satış sənədini açın.

   > **Şəkil əlavə ediləcək —** `media/user-guide/reports/sales/images/screen-01.png`: Satış hesabatının filtrləri və nəticə qrafiki/cədvəli.

## Lüğət

| Termin | Bu səhifədəki mənası |
| --- | --- |
| Satış analitikası | Satış məbləği və miqdarını müxtəlif kəsimlərdə ümumiləşdirən hesabatdır. |
| Ölçü | Hesabatı məhsul, müştəri, dövr və ya başqa kateqoriya üzrə qruplaşdıran göstəricidir. |

## FAQ

### POS satışı və ERP satış sənədi eyni nəticədə görünür?

Hesabatın hansı satış mənbələrini əhatə etdiyini ekran filtr və izahından yoxlayın; POS qeydi ilə ERP sənədinin sayılma qaydasını qarışdırmayın.

### Satış hesabatı sifariş yaradır?

Xeyr. Yeni əməliyyat üçün **Satış → Sifarişlər** və ya **Satışlar** səhifəsindən istifadə edin.
