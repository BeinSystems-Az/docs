# Maliyyə hesabatını təhlil etmək

**Hesabatlar → Maliyyə** səhifəsi pul hesabları və maliyyə hərəkətlərini seçilmiş filtrlərlə ümumiləşdirir.

## İstifadə qaydası

1. **Hesabatlar → Maliyyə** səhifəsini açın.
2. Hesabatda olan dövr, filial, valyuta və pul hesabı filtrlərini seçin.
3. Nəticəni yeniləyin və daxilolma, məxaric, xərc və hesablararası transferi nəzərə alaraq göstəriciləri tutuşdurun.
4. Konkret məbləği **Ödənişlər**, **Xərclər** və ya **Transferlər** səhifəsindəki əməliyyatla müqayisə edin.

   > **Şəkil əlavə ediləcək —** `media/user-guide/reports/finance/images/screen-01.png`: Hesab və dövr filtrləri ilə maliyyə hesabatı.

## Lüğət

| Termin | Bu səhifədəki mənası |
| --- | --- |
| Maliyyə hərəkəti | Pul hesabına daxil olan və ya ondan çıxan qeyddir. |
| Pul dövriyyəsi | Seçilmiş dövrdə hesablar üzrə daxilolma və çıxışların cəmidir. |

## FAQ

### Hesabatla hesab kartının balansı fərqlənir?

Eyni tarix, hesab, valyuta və təsdiq statusunu müqayisə edin. Hesablararası transferin hər iki tərəfinin daxil olub-olmadığını da yoxlayın.

### Hesabat əməliyyat yaradır?

Xeyr. Hesabat yalnız mövcud əməliyyatları ümumiləşdirir.
