# Anbar hesabatına baxmaq

**Hesabatlar → Anbar** səhifəsi məhsul qalıqları və stok hərəkətlərini hesabat filtrləri üzrə ümumiləşdirir. Bu görünüş ehtiyat qərarları üçündür; stok sənədini özü yaratmır.

## İstifadə qaydası

1. **Hesabatlar → Anbar** səhifəsini açın.
2. Hesabatda olan dövr, filial, anbar, kateqoriya və məhsul filtrlərini seçin.
3. Nəticəni yeniləyib məhsul, miqdar və hərəkət göstəricilərini seçilmiş əhatə ilə müqayisə edin.
4. Fərqi araşdırmaq üçün məhsulun stok kartına və mənbə anbar sənədlərinə keçin.

   > **Şəkil əlavə ediləcək —** `media/user-guide/reports/warehouse/images/screen-01.png`: Anbar hesabatında dövr və anbar filtrləri, məhsul nəticələri.

| --- | --- |
| Hesabat əhatəsi | Hesabata daxil edilən tarix, filial və anbar seçimləridir. |
| Mənbə sənəd | Hesabat rəqəmini yaradan stok əməliyyatıdır. |

## FAQ

### Hesabatdan stok düzəlişi etmək olar?

Xeyr. Faktiki sayım fərqini **Anbar → İnventarizasiyalar** sənədində qeydə alın.

### Məbləğlər başqa anbarla tutuşmur?

Eyni filial, anbar, tarix və məhsul filtrlərini seçdiyinizi yoxlayın.
