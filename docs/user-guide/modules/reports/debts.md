# Hesablaşma borclarını təhlil etmək

**Hesabatlar → Borclar** səhifəsi tərəfdaşlar üzrə debitor və kreditor qalıqlarını nəzərdən keçirməyə kömək edir.

## İstifadə qaydası

1. **Hesabatlar → Borclar** səhifəsini açın.
2. Hesabatın təklif etdiyi tarix, filial, tərəfdaş və hesablaşma istiqaməti filtrlərini seçin.
3. Nəticədə tərəfdaşın açıq qalığını və onu yaradan faktura/ödəniş qeydlərini müqayisə edin.
4. Ödəniş tələb olunarsa **Maliyyə → Ödənişlər** səhifəsində ayrıca sənəd yaradın.

   > **Şəkil əlavə ediləcək —** `media/user-guide/reports/debts/images/screen-01.png`: Borc hesabatında tərəfdaş qalığı və dövr seçimi.

## Lüğət

| Termin | Bu səhifədəki mənası |
| --- | --- |
| Debitor qalığı | Müştərilərdən alınmalı məbləğdir. |
| Kreditor qalığı | Təchizatçılara ödənilməli məbləğdir. |
| Hesablaşma | Faktura, qaytarma və ödənişlərin tərəfdaş üzrə uzlaşdırılmasıdır. |

## FAQ

### Hesabatda borc görünür, amma ödəniş etmişik. Nəyi yoxlayım?

Ödənişin tərəfdaşını, tarixini, valyutasını, təsdiq statusunu və hesabat dövrünü yoxlayın.

### Bu hesabatdan borcu bağlamaq olur?

Hesabat borc məlumatını göstərir. Faktiki ödənişi Maliyyə modulunda ayrıca yaradın və təsdiq edin.
