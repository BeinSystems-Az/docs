# Rəhbərlik hesabatına baxmaq

**Hesabatlar → Rəhbərlik** səhifəsi şirkətin ümumi biznes göstəricilərini bir görünüşdə izləmək üçündür. Göstəricilər üzrə qərar verməzdən əvvəl onların tarix və filial əhatəsini yoxlayın.

## İstifadə qaydası

1. **Hesabatlar → Rəhbərlik** səhifəsini açın.
2. Səhifədəki dövr və filial seçimlərini göstərin, hesabatı yeniləyin.
3. Ümumi göstəriciləri əlaqəli satış, satınalma, maliyyə və anbar hesabatları ilə tutuşdurun.
4. Gözlənilməz göstəricini araşdırmaq üçün həmin moduldakı ilkin sənəd siyahısına keçin.

   > **Şəkil əlavə ediləcək —** `media/user-guide/reports/executive/images/screen-01.png`: Rəhbərlik hesabatında dövr filtri və əsas KPI kartları.

## Lüğət

| Termin | Bu səhifədəki mənası |
| --- | --- |
| Rəhbərlik göstəricisi | Bir neçə biznes sahəsinin məlumatını ümumiləşdirən nəticədir. |
| KPI | Şirkətin nəticəsini ölçmək üçün izlənən əsas göstəricidir. |

## FAQ

### Rəhbərlik göstəricisi necə hesablandığını haradan öyrənim?

Göstəricinin başlığını və izahını yoxlayın, sonra eyni dövr üzrə əlaqəli ixtisaslaşmış hesabatı açın.

### Rəhbərlik hesabatı ilkin sənədi dəyişir?

Xeyr. Hesabat yalnız analiz məlumatını göstərir. İlkin sənədi dəyişmək üçün uyğun modulu açın.
