# Satınalma hesabatını təhlil etmək

**Hesabatlar → Satınalma** səhifəsi təchizat və alış göstəricilərini seçilmiş dövr və tərəfdaşlar üzrə göstərir.

## İstifadə qaydası

1. **Hesabatlar → Satınalma** səhifəsini açın.
2. Tarix aralığını və hesabatın təqdim etdiyi təchizatçı, filial, məhsul və status filtrlərini seçin.
3. Hesabatı yeniləyib alış miqdarı və məbləğləri müqayisə edin.
4. Fərqli nəticəni araşdırmaq üçün təchizatçı üzrə **Təchizat → Sifarişlər**, **Alışlar** və ya **Fakturalar** siyahılarında eyni dövrü yoxlayın.

   > **Şəkil əlavə ediləcək —** `media/user-guide/reports/procurement/images/screen-01.png`: Təchizatçı və dövr filtrləri, satınalma nəticələri.

## Lüğət

| Termin | Bu səhifədəki mənası |
| --- | --- |
| Satınalma dövrü | Hesabata daxil edilən alış sənədlərinin tarix aralığıdır. |
| Təchizatçı | Alış əməliyyatının qarşı tərəfidir. |

## FAQ

### Sifariş, alış və faktura eyni metrik kimi sayılır?

Bunlar ayrı sənəd növləridir. Hesabatın başlıq və filtr izahından hansı sənəd statuslarının nəticəyə düşdüyünü yoxlayın.

### Hesabatdan sifariş vermək mümkündür?

Xeyr. Sifarişi **Təchizat → Sifarişlər** səhifəsində ayrıca yaradın.
