# Müştəridən satış qaytarması qəbul etmək

Satış qaytarması müştərinin geri verdiyi məhsul və geri ödəniləcək məbləği qeydə alır. Məhsulun anbara qaytarılmasını düzgün göstərmək üçün qaytarma sənədində uyğun anbarı və faktiki miqdarı seçin.

## İstifadə qaydası

### Qaytarma sənədini başladın

1. Sol menyudan **Satış → Qaytarmalar** bölməsini açın.

   > **Şəkil əlavə ediləcək —** `media/user-guide/sales/sale-returns/images/screen-01.png`: Satış menyusunda Qaytarmalar seçimi və sənəd siyahısı.

2. Siyahının yuxarısındakı **Yeni** düyməsini seçin. Satış sənədindən başlayırsınızsa, həmin sənəddə **Sənəd yarat → Satış qaytarması** seçin.

### Müştərini və qaytarılan malları daxil edin

3. **Müştəri**, məhsulun qəbul ediləcəyi **Anbar** və **Valyuta** sahələrini seçin. Tarix və mənbə satış sənədini yoxlayın.

4. **Məhsullar** səhifəsində geri alınan məhsulları və faktiki miqdarları daxil edin. Qiymət, endirim və vergi hesablamasını ilkin satış şərtləri ilə tutuşdurun.

   > **Şəkil əlavə ediləcək —** `media/user-guide/sales/sale-returns/images/screen-02.png`: Müştəri, anbar və qaytarılan məhsul sətrində miqdar/qiymət görünür.

5. **Yekun məbləğ** və geri qaytarılacaq məbləği yoxlayın. Mühasibatlıq modulu aktivdirsə, **Müxabirləşmə** səhifəsində yaranan nəticəni nəzərdən keçirin.

### Qaytarmanı təsdiqləyin

6. Məlumatlar düzgün olduqda **Təsdiq** seçin. Qaytarılan məhsulun seçilmiş anbarda qalığa daxil olduğunu və müştəri hesablaşmasının dəyişdiyini yoxlayın.

   > **Video əlavə ediləcək —** `media/user-guide/sales/sale-returns/videos/walkthrough-01.mp4`: Satış sənədindən qaytarma açılması, faktiki miqdarın daxil edilməsi, təsdiq və stok nəticəsinin yoxlanması.

## FAQ

### Satış qaytarması təsdiqlənəndə stok artırmı?

Bəli, qaytarılan məhsul sənəddə seçilmiş anbara daxil edilir. Faktiki qəbul edilməyən məhsulu qaytarma sətrinə daxil etməyin.

### Qaytarma mənbə satış sənədindən yaradılmalıdırmı?

Mümkündürsə, satış sənədində **Sənəd yarat → Satış qaytarması** seçin və köçürülən məlumatı yoxlayın.

### Satış qaytarması müştəri borcunu necə dəyişir?

Qaytarma təsdiqindən sonra müştəri hesablaşması dəyişə bilər. Dəqiq nəticəni **Borclar** bölməsində yoxlayın.
