# Satış sənədi ilə satışı rəsmiləşdirmək

Satış sənədi müştəriyə faktiki verilən məhsul və xidmətləri qeydə alır. Sənədi **Təsdiq** etdikdə məhsul miqdarı seçilmiş anbardan çıxılır; sifarişin təsdiqi özü bu stok çıxışını yaratmır.

## İstifadə qaydası

### Satış sənədini açın

1. Sol menyudan **Satış → Satışlar** bölməsinə keçin.

   > **Şəkil əlavə ediləcək —** `media/user-guide/sales/sale-receipts/images/screen-01.png`: Satış menyusunda Satışlar seçimi və satış sənədləri siyahısı.

2. Yeni satış üçün **Yeni** düyməsini seçin. Sifarişdən davam edirsinizsə, sifariş kartında **Sənəd yarat → Satış sənədi** seçin və köçürülən məhsul sətirlərini yoxlayın.

### Müştəri və məhsulları daxil edin

3. Başlıqda **Müştəri**, **Anbar** və **Valyuta** seçin. Tarix, filial, layihə və qeyd məlumatlarını əməliyyata uyğun göstərin.

4. **Məhsullar** səhifəsində satılan məhsulları əlavə edin. Qiymət növünü, ölçü vahidini, miqdarı və qiyməti yoxlayın. Məhsul kartından gələn qiymət avtomatik tətbiq olunarsa, satış razılaşmasına uyğunluğunu təsdiqləyin.

   > **Şəkil əlavə ediləcək —** `media/user-guide/sales/sale-receipts/images/screen-02.png`: Müştəri/anbar və məhsul sətri seçilmiş, miqdar və qiymət daxil edilmiş forma.

5. Endirim və vergi məlumatlarını əməliyyata uyğun daxil edin. Hesablanmış **Məbləğ**, **ƏDV məbləği** və **Yekun məbləğ** dəyərlərini müştəriyə təqdim edilən şərtlərlə müqayisə edin.

### Satışı təsdiqləyin və nəticəni yoxlayın

6. Sənədi yadda saxlayın. Müştəri, anbar, məhsul, miqdar, qiymət və yekunlar düzgün olduqda **Təsdiq** düyməsini seçin.

7. Məhsul qalığının seçilmiş anbarda azaldığını **Anbar qalığı** hesabatında yoxlayın. Aktivdirsə **Müxabirləşmə** səhifəsində vergi və maliyyə nəticəsinə baxın.

   > **Video əlavə ediləcək —** `media/user-guide/sales/sale-receipts/videos/walkthrough-01.mp4`: Sifarişdən satış sənədinin yaradılması, faktiki miqdarların yoxlanması, təsdiq və anbar nəticəsinin izlənməsi.

## FAQ

### Təsdiqlənmiş satış sifarişi stokdan məhsul çıxırmı?

Xeyr. Sifariş plan və öhdəliyi qeydə alır. Faktiki satış üçün **Satış sənədi** yaradıb təsdiqləyin.

### Satış sənədini təsdiqləyəndə nə dəyişir?

Seçilmiş anbardakı məhsul qalığı azalır. Mühasibatlıq və vergi sazlamalarına görə maliyyə nəticələri də yarana bilər.

### Məhsulun qiyməti təklif olunandan fərqli ola bilərmi?

Bəli. Satış sənədində tətbiq edilən qiymətin müştəri ilə razılaşdırılmış qiymət olmasını təsdiqdən əvvəl yoxlayın.
