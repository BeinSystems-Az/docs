# Keyfiyyət yoxlaması aparmaq

Keyfiyyət yoxlaması məhsul və ya istehsal mərhələsinin nəticəsini plandakı meyarlarla müqayisə edir. Nəticə və uyğunsuzluq qeydi yoxlama sənədində saxlanılır.

## İstifadə qaydası

1. **İstehsalat → Keyfiyyət yoxlamaları** səhifəsini açıb yoxlama qeydini tapın və ya **Yeni** seçin.
2. Yoxlamanı aid olduğu istehsal sifarişi, məhsul və keyfiyyət planı ilə əlaqələndirin.
3. Plandakı hər meyar üçün faktiki ölçmə/nəticəni daxil edin.
4. Uyğunsuzluq varsa nəticə və qeyd sahəsində səbəbi yazın.
5. Yoxlamanı yadda saxlayın və nəticəni sifarişin gedişində/uyğunluq statusunda yoxlayın.

   > **Şəkil əlavə ediləcək —** `media/user-guide/manufacturing/quality-inspections/images/screen-01.png`: Plan meyarı və daxil edilən faktiki nəticə.

## Lüğət

| Termin | Bu səhifədəki mənası |
| --- | --- |
| Yoxlama | Məhsul və ya prosesin meyarlara uyğunluğunu qeyd edən sənəddir. |
| Faktiki nəticə | Yoxlama zamanı ölçülən dəyər və ya seçilmiş qərardır. |
| Uyğunsuzluq | Faktiki nəticənin plandakı tələbə cavab verməməsidir. |

## FAQ

### Yoxlama nəticəsi sifarişi avtomatik dayandırır?

Yoxlamanın sifarişə təsirini **İstehsalın gedişi** və sifariş statusunda yoxlayın; nəticəni ayrıca qiymətləndirin.

### Planda istifadə edilən meyar yoxdur?

Əvvəl **Keyfiyyət planları** səhifəsində uyğun plan və meyarları hazırlayın.
