# İstehsal qeydini aparmaq

**İstehsalat → İstehsal** səhifəsində istehsal fəaliyyəti üzrə qeydlər izlənir. Plan sifarişi ilə istehsal nəticəsi ayrı saxlandığı üçün qeyd açmazdan əvvəl onun mənbə sifarişini yoxlayın.

## İstifadə qaydası

1. **İstehsalat → İstehsal** siyahısını açıb aid olduğu istehsal qeydini axtarın.
2. Yeni qeyd lazımdırsa **Yeni** seçib formada göstərilən sifariş, məhsul, miqdar və tarix əlaqələrini doldurun.
3. Qeydi yadda saxlayıb istehsal sifarişi ilə uyğunluğunu yoxlayın.
4. Stok və istehsal nəticəsini yalnız uyğun sifarişin faktiki çıxış/ qəbul əməliyyatı ilə tamamlayın.

   > **Şəkil əlavə ediləcək —** `media/user-guide/manufacturing/productions/images/screen-01.png`: İstehsal qeydi siyahısı və əlaqəli sifarişə keçid.

## FAQ

### İstehsal siyahısı hazır məhsul qalığını göstərir?

Qalığın artmasını anbar qalığı hesabatında yoxlayın. İstehsal qeydini anbara qəbul əməliyyatı ilə qarışdırmayın.

### İstehsal sifarişləri haradadır?

Onlar ayrıca **İstehsalat → İstehsal sifarişləri** səhifəsindədir.
