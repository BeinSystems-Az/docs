# İş mərkəzi yaratmaq

İş mərkəzi istehsal marşrutunda istifadə edilən avadanlıq, istehsal sahəsi və ya əməliyyat resursudur.

## İstifadə qaydası

1. **İstehsalat → Məlumat kitabçası → İş mərkəzləri** səhifəsini açıb **Yeni** seçin.
2. İş mərkəzinin formasında tələb olunan ad və tanıdıcı məlumatları daxil edin.
3. İstifadə olunacaqsa iş mərkəzini aktiv saxlayıb yadda saxlayın.
4. **Marşrutlar** formasında yeni iş mərkəzinin seçilə bildiyini yoxlayın.

   > **Şəkil əlavə ediləcək —** `media/user-guide/manufacturing/work-centers/images/screen-01.png`: İş mərkəzi yaratma forması və marşrutda seçim.

## Lüğət

| Termin | Bu səhifədəki mənası |
| --- | --- |
| İş mərkəzi | İstehsal əməliyyatının aparıldığı resurs və ya sahədir. |
| Marşrut | İş mərkəzlərini mərhələlər üzrə birləşdirən istehsal ardıcıllığıdır. |

## FAQ

### İş mərkəzi yaratmaq istehsal əməliyyatı başladır?

Xeyr. İş mərkəzi istinad məlumatıdır; istehsal əməliyyatı sifariş və icra addımları ilə aparılır.

### İstifadə olunan iş mərkəzini silə bilərəm?

Əlaqəli marşrutlar varsa silmə məhdud ola bilər. İstifadədən çıxarmaq üçün aktivlik statusunu yoxlayın.
