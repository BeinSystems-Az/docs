# Keyfiyyət planı yaratmaq

Keyfiyyət planı məhsul və istehsal prosesində yoxlanacaq meyarları müəyyən edir. Plan yoxlama qeydində nəticələrin eyni qaydada toplanmasına kömək edir.

## İstifadə qaydası

1. **İstehsalat → Məlumat kitabçası → Keyfiyyət planları** səhifəsini açıb **Yeni** seçin.
2. Planı aid olduğu məhsul və ya proseslə əlaqələndirin.
3. Yoxlama meyarlarını və formanın tələb etdiyi limit/ölçü məlumatlarını daxil edin.
4. Planı yadda saxlayın və keyfiyyət yoxlaması yaradılarkən seçilə bildiyini yoxlayın.

   > **Şəkil əlavə ediləcək —** `media/user-guide/manufacturing/quality-plans/images/screen-01.png`: Məhsul/proses və meyar sətirləri olan plan.

## Lüğət

| Termin | Bu səhifədəki mənası |
| --- | --- |
| Keyfiyyət planı | Yoxlanacaq xüsusiyyət və meyarların şablonudur. |
| Meyar | Uyğunluğu qiymətləndirmək üçün ölçülən tələbdir. |
| Limit | Meyar üçün qəbul edilən hədd və ya intervaldır. |

## FAQ

### Keyfiyyət planı yoxlama nəticəsini özü qeydə alır?

Xeyr. Plan meyarları müəyyən edir; faktiki nəticəni **Keyfiyyət yoxlamaları** səhifəsində daxil edin.

### Aktiv olmayan plan yoxlama formasında görünür?

İstifadə üçün aktiv plan seçin. Seçim siyahısında görünmürsə, planın statusunu yoxlayın.
