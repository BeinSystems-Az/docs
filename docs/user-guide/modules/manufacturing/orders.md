# İstehsal sifarişini icra etmək

İstehsal sifarişi planı və faktiki istehsal qeydlərini birləşdirir. Material sərfi və hazır məhsulun anbara qəbulu təsdiqlənmiş sifarişin icra addımları ilə ayrıca qeydə alınır.

## İstifadə qaydası

### Sifariş planını yaradın

1. **İstehsalat → İstehsal sifarişləri** bölməsinə keçin və **Yeni** seçin.

2. **Filial**, **Sifariş №**, istehsala aid **Çıxış anbarı** və **Giriş anbarı**nı göstərin. Aktiv **Resept** seçin; resept material və hazır məhsul tərkibini doldurarsa, miqdarları plana uyğun yoxlayın.

3. Plan partiya miqdarını, tarixləri və lazım olan qeyd/lokasiyaları daxil edin. **Məhsullar və tərkib** səhifəsində planlanan çıxış və materialları yoxlayın.

   > **Şəkil əlavə ediləcək —** `media/user-guide/manufacturing/orders/images/screen-01.png`: İstehsal sifarişində filial, anbarlar, resept və material/çıxış planı.

### Sifarişi təsdiqləyib faktiki icranı qeyd edin

4. Plan düzgün olduqda **Təsdiqlə** seçin. Təsdiqdən sonra sifarişin statusunu və icra səhifələrini yoxlayın.

5. Sifariş kartının **İstehsal sənədləri** səhifəsində partiya, material sərfi, mərhələ və faktiki çıxış qeydlərini iş prosesinizə uyğun tamamlayın. Yeni icra panelində mövcud olan **Yeni icra partiyası**, **Material sərf et**, **Faktiki çıxış** və **Partiyanı anbara qəbul et** əməliyyatlarını istifadə edin.

6. Material miqdarını faktiki sərfə uyğun daxil edin. Keyfiyyət yoxlaması tələb olunursa, nəticəni uyğun yoxlama qeydində tamamlayın.

7. Hazır məhsulu anbara qəbul etməzdən əvvəl faktiki istehsal miqdarını və giriş anbarını yoxlayın. Qəbul əməliyyatını tamamladıqdan sonra stok qalığını və sifarişin icra vəziyyətini yoxlayın.

   > **Video əlavə ediləcək —** `media/user-guide/manufacturing/orders/videos/walkthrough-01.mp4`: Sifariş planlamaq, təsdiqləmək, material sərfini və faktiki çıxışı daxil etmək, məhsulu anbara qəbul etmək.

## FAQ

### Sifarişi təsdiqləmək hazır məhsulu anbara daxil edirmi?

Xeyr. Təsdiq istehsal planını icraya açır. Faktiki çıxışı qeydə alıb **Partiyanı anbara qəbul et** əməliyyatını tamamlayın.

### Resept seçiləndə materiallar dəyişdirilə bilər?

Resept sifarişdə başlanğıc tərkibi doldurur. İcazə və sifariş vəziyyətindən asılı olaraq plan materialını düzəltmək və ya faktiki sərfi ayrıca daxil etmək imkanı ola bilər.

### Faktiki sərf plan miqdarından fərqli olsa nə etməliyəm?

İstehsalatda həqiqətən sərf olunan materialı faktiki sərf qeydində göstərin. Fərqin səbəbini iş prosedurunuza uyğun qeyd edin.
