# İstehsal marşrutu yaratmaq

Marşrut istehsal işlərinin keçəcəyi ardıcıllığı müəyyən edir. Marşrutda istifadə olunan iş mərkəzlərinin əvvəlcədən yaradıldığını yoxlayın.

## İstifadə qaydası

1. **İstehsalat → Məlumat kitabçası → Marşrutlar** səhifəsini açıb **Yeni** seçin.
2. Marşrutun adını və məhsul/proseslə bağlı tələb olunan məlumatları daxil edin.
3. Əməliyyat sətirlərini düzgün ardıcıllıqla əlavə edib hər əməliyyata uyğun iş mərkəzini seçin.
4. Marşrutu yadda saxlayın və istehsal sifarişində tətbiq edilə bilən olduğunu yoxlayın.

   > **Şəkil əlavə ediləcək —** `media/user-guide/manufacturing/routings/images/screen-01.png`: Ardıcıllıqlı əməliyyatlar və iş mərkəzi seçimi.

## Lüğət

| Termin | Bu səhifədəki mənası |
| --- | --- |
| Marşrut | İstehsal əməliyyatlarının ardıcıllığıdır. |
| Əməliyyat | Marşrutdakı ayrıca istehsal mərhələsidir. |
| İş mərkəzi | Əməliyyatın aparıldığı istehsal yeri və ya resursdur. |

## FAQ

### Marşrut olmadan istehsal sifarişi yaratmaq olar?

Bu, sifariş formasında marşrutun tələb olunmasından asılıdır. Tələb olunursa əvvəl marşrut yaradın.

### Əməliyyat ardıcıllığını dəyişəndə əvvəlki sifariş dəyişir?

Əvvəl yaradılmış sifarişdə marşrut mərhələlərini ayrıca yoxlayın; şablon dəyişikliyinin geriyə tətbiq olunduğunu güman etməyin.
