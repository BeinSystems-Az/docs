# İstehsalat hesabatına baxmaq

İstehsalat hesabatları seçilmiş filtrlərlə plan və faktiki istehsal göstəricilərini təhlil etməyə kömək edir.

## İstifadə qaydası

1. **İstehsalat → İstehsalat hesabatları** səhifəsini açın.
2. Hesabatın təklif etdiyi dövr, məhsul və sifariş filtrlərini seçin.
3. Nəticəni yeniləyib plan miqdarı, material sərfi və faktiki çıxışı müqayisə edin.
4. Fərqi araşdırmaq üçün mənbə istehsal sifarişini və onun material/çıxış qeydlərini açın.

   > **Şəkil əlavə ediləcək —** `media/user-guide/manufacturing/reports/images/screen-01.png`: Filtrli istehsal hesabatı və plan/fakt göstəriciləri.

## Lüğət

| Termin | Bu səhifədəki mənası |
| --- | --- |
| Plan miqdarı | İstehsal sifarişində nəzərdə tutulan çıxış və sərf miqdarıdır. |
| Faktiki çıxış | İstehsalda həqiqətən əldə olunmuş hazır məhsul miqdarıdır. |
| Faktiki sərf | İstehsalda həqiqətən istifadə edilmiş material miqdarıdır. |

## FAQ

### Hesabat plan və faktı niyə fərqli göstərir?

İstehsal sifarişində faktiki sərf, məhsul qəbulu və tarix/sifariş filtrlərini yoxlayın.

### Hesabatdan istehsal sifarişi yaratmaq olur?

Xeyr. Yeni sifarişi **İstehsalat → İstehsal sifarişləri** səhifəsində başladın.
