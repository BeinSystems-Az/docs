# BOM və formula yaratmaq

BOM və formula istehsal ediləcək məhsulu və onun üçün tələb olunan material tərkibini müəyyən edir. İstehsal sifarişində istifadə olunması üçün uyğun aktiv BOM-u saxlayın.

## İstifadə qaydası

1. **İstehsalat → Məlumat kitabçası → BOM və formulalar** səhifəsini açıb **Yeni** seçin.
2. İstehsal ediləcək məhsulu və reseptin çıxış miqdarını seçin.
3. Material sətirlərinə komponentləri və hər çıxış miqdarı üçün tələb olunan sərfi daxil edin.
4. Sətir cəmlərini yoxlayıb BOM-u yadda saxlayın və istifadə olunacaqsa aktiv edin.
5. **İstehsal sifarişləri** formasında BOM-u seçib gələn material tərkibini nəzərdən keçirin.

   > **Şəkil əlavə ediləcək —** `media/user-guide/manufacturing/boms/images/screen-01.png`: Hazır məhsul/çıxış miqdarı və material komponentləri olan BOM.

## Lüğət

| Termin | Bu səhifədəki mənası |
| --- | --- |
| BOM | Məhsul istehsalı üçün materialların və miqdarların siyahısıdır. |
| Komponent | İstehsalda sərf edilən xammal və ya yarımfabrikatdır. |
| Çıxış miqdarı | BOM-un hansı hazır məhsul miqdarı üçün material sərfini göstərdiyini bildirir. |

## FAQ

### BOM dəyişəndə açıq sifarişlərin materialları dəyişir?

Mövcud sifarişdəki planı açıb yoxlayın; BOM dəyişikliyinin əvvəl yaradılmış sifarişə avtomatik tətbiq olunduğunu fərz etməyin.

### BOM olmadan istehsal sifarişi açıla bilər?

Sifariş formasında BOM-un məcburiliyini yoxlayın. İstifadə olunan istehsal prosesində tələb olunursa, əvvəl aktiv BOM yaradın.
