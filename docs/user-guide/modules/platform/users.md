# İstifadəçi və rol idarəetməsi

İstifadəçi qeydində giriş adı, şəxsi məlumat, rol və filial əhatəsi saxlanılır. Dəqiq sahələr və əməliyyatlar hesabın icazəsinə görə fərqlənə bilər.

## İstifadə qaydası

### İstifadəçi yaradın

1. **Sazlamalar → İstifadəçilər** bölməsini açın və **Yeni** seçin.
2. Tələb olunan **İstifadəçi adı**, **Ad** və **Rollar** məlumatlarını daxil edin.
3. Lazım olduqda soyad, telefon, e-poçt, standart filial, icazəli filiallar və əməkdaş kartı seçin.
4. Formanı yadda saxlayıb siyahıda hesabı yoxlayın. Əməkdaş seçilmədikdə sistem yeni əməkdaş kartı yarada bilər.

   > **Şəkil əlavə ediləcək —** `media/user-guide/platform/users/images/screen-01.png`: İstifadəçi adı, rol və filial əhatəsi olan istifadəçi forması.

### Rol və filial əhatəsini yoxlayın

5. İstifadəçinin rolunu açıb ona uyğun icazələri yoxlayın. İş üçün tələb olunan səlahiyyətləri verin.
6. Standart filialın və icazəli filialların düzgün olduğunu yoxlayın; sonra istifadəçi siyahısına qayıdıb dəyişiklikləri təsdiqləyin.

## Lüğət

| Termin | Bu səhifədəki mənası |
| --- | --- |
| İstifadəçi adı | Giriş hesabını tanıdan tələb olunan login dəyəridir. |
| Rol | İstifadəçiyə verilən icazələr dəstidir. |
| Standart filial | İstifadəçi üçün başlanğıcda seçilən filialdır. |
| İcazəli filiallar | İstifadəçinin məlumat görə və əməliyyat apara biləcəyi filiallardır. |
| Əməkdaş kartı | HR məlumatlarında həmin istifadəçi ilə əlaqələndirilən əməkdaş qeydidir. |

## FAQ

### İstifadəçi adı və rol olmadan hesab yaratmaq olar?

Xeyr. İstifadəçi adı, ad və rol tələb olunan sahələrdir.

### Əməkdaş seçməsəm nə baş verir?

İstifadəçi forması yeni əməkdaş kartı yarada bilər. Təkrar əməkdaş yaranmaması üçün mövcud kartı əvvəlcədən axtarın.

### İstifadəçi niyə müəyyən filialın məlumatını görmür?

Standart filialı, icazəli filiallar siyahısını və həmin istifadəçinin rol icazələrini yoxlayın.
