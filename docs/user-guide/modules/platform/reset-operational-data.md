# Əməliyyat məlumatlarını sıfırlamaq

Bu inzibati əməliyyat əməliyyat məlumatlarını geri qaytarılmadan silir. Yalnız şirkət məlumatları sıfırlanmalı olduqda və bu məlumatların saxlanması tələb edilmədikdə istifadə edin.

## İstifadə qaydası

### Silinmə əhatəsini yoxlayın

1. **Sazlamalar → Əməliyyat məlumatlarını sıfırla** səhifəsini açın.
2. Xəbərdarlıqda sənədlərin, stok hərəkətlərinin, mühasibat yazılışlarının, POS satışlarının və əməliyyat tarixçəsinin həmişəlik silinəcəyini yoxlayın.
3. Qorunan məlumatları oxuyun: məhsullar, tərəf-müqabillər, istifadəçilər, rollar, şirkət sazlamaları, hesab planı və kassa konfiqurasiyası saxlanılır. POS cihazlarını yenidən aktivləşdirmək lazım gələcək.

### Sıfırlamanı başladın

4. Əməliyyatı icra etmək səlahiyyətiniz və şirkətin məlumatları üzrə təsdiqiniz olduğuna əmin olun.
5. Təsdiq sahəsinə dəqiq **SIFIRLA** yazın.
6. **Əməliyyat məlumatlarını sil** düyməsini basın və nəticə bildirişini gözləyin.

   > **Şəkil əlavə ediləcək —** `media/user-guide/platform/reset-operational-data/images/screen-01.png`: Silinmə xəbərdarlığı, qorunan məlumat siyahısı və dəqiq təsdiq sahəsi.

## Lüğət

| Termin | Bu səhifədəki mənası |
| --- | --- |
| Əməliyyat məlumatları | Silinmə əhatəsində olan sənəd, stok, mühasibat, POS və əməliyyat tarixçəsidir. |
| Qorunan məlumatlar | Sıfırlamadan sonra saxlanılan kataloq, istifadəçi, şirkət və hesab sazlamalarıdır. |
| SIFIRLA | Əməliyyatı başlatmaq üçün təsdiq sahəsinə daxil edilməli dəqiq sözdür. |

## FAQ

### Sıfırlanan məlumatları geri qaytarmaq olar?

Xeyr. Səhifə əməliyyatın geri qaytarılmadığını bildirir. Başlatmazdan əvvəl silinmə əhatəsini və şirkətin məlumat saxlanması tələblərini yoxlayın.

### POS cihazlarında nə baş verəcək?

POS cihazlarının konfiqurasiya qeydi saxlanılır, lakin cihazları yenidən aktivləşdirmək tələb olunur.
