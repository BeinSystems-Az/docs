# ERP modullarını aktiv və ya qeyri-aktiv etmək

**Ayarlar → Sistem → Modullar** səhifəsində tenantda aktiv olan biznes modulları göstərilir. Modulun söndürülməsi ona bağlı menyu və əməliyyatlara təsir edə bilər.

## İstifadə qaydası

1. Siyahıda modulun adını, hazırkı statusunu və varsa ondan asılı modulları yoxlayın.
2. Aktivliyi dəyişməzdən əvvəl modulda sənəd və əlaqəli proseslərin olub-olmadığını müəyyən edin.
3. Dəyişikliyi modul sətrindəki status nəzarətindən edin və təsdiq pəncərəsində təsiri oxuyun.
4. Təsdiqdən sonra ana menyuda və modulun səhifələrində yeni vəziyyəti yoxlayın.

   > **Şəkil əlavə ediləcək —** `media/user-guide/platform/settings/modules/images/screen-01.png`: Modul statusları və deaktiv etmə təsdiq pəncərəsi.

## Lüğət

| Termin | Bu səhifədəki mənası |
| --- | --- |
| Aktiv modul | Tenantda modula aid imkanların istifadəyə açıq vəziyyətidir. |
| Asılı modul | Başqa modulun prosesindən və ya məlumatından istifadə edən moduldur. |

## FAQ

### Modulu söndürəndə sənədlər silinir?

Modulun deaktiv edilməsi və məlumatların silinməsi eyni əməliyyat deyil. Təsdiq pəncərəsindəki xəbərdarlığı oxuyun; məlumatı silmək üçün istifadə etməyin.

### Modulu yenidən aktiv etmək olar?

İcazə və mövcud modul statusuna görə aktivlik siyahıdan dəyişdirilə bilər.
