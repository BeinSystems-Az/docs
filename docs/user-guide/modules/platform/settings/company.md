# Şirkət məlumatlarını yeniləmək

Şirkət məlumatları ümumi profil və iş mühitində görünən əsas əlaqə məlumatlarını saxlayır. Şirkət adı, e-poçt və saat qurşağı tələb olunur.

## İstifadə qaydası

### Şirkət profilini açın

1. **Ayarlar → Təşkilat → Şirkət məlumatları** səhifəsini açın.
2. **Şirkət adı**, **Şirkət e-maili** və **Saat qurşağı** sahələrini doldurun.
3. Əlaqə üçün **Şirkət telefonu**, vergi məlumatı üçün **VÖEN** sahəsini yoxlayın. Şirkət məlumatına uyğun olanı daxil edin.
4. Saat qurşağını şirkətin gündəlik iş apardığı yerə uyğun seçin. Bu parametr tarix və vaxtların göstərilməsinə təsir edə bilər.

   > **Şəkil əlavə ediləcək —** `media/user-guide/platform/settings/company/images/screen-01.png`: Şirkət adı, e-mail, telefon, VÖEN və saat qurşağı sahələri.

### Yadda saxlayın və görünüşü yoxlayın

5. **Yadda saxla** seçin. Tələb olunan sahə boşdursa, onu tamamlayıb yenidən saxlayın.
6. Səhifəni yenidən açın və şirkət məlumatlarının saxlandığını yoxlayın.

## Lüğət

| Termin | Bu səhifədəki mənası |
| --- | --- |
| Şirkət e-maili | Şirkətin əsas əlaqə e-poçt ünvanıdır. |
| VÖEN | Şirkətin vergi ödəyicisi kimi qeydiyyat identifikatorudur. |
| Saat qurşağı | Tarix və vaxtların şirkətin yerli vaxtına görə göstərilməsini təyin edir. |

## FAQ

### Şirkət adı və e-mail boş qala bilər?

Xeyr. Hər iki sahə məcburidir. Saat qurşağı da tələb olunan parametrdir.

### Şirkət məlumatları alış və satış sənədlərini dəyişir?

Bu səhifə şirkətin profil məlumatlarını saxlayır. Sənəd məbləğlərinin dəyişdiyini nəzərdə tutmur.

### Səhv saat qurşağı seçsəm nəyi yoxlamalıyam?

Saat və tarix göstərilən ekranları müqayisə edin, sonra düzgün saat qurşağını seçib məlumatı yadda saxlayın.
