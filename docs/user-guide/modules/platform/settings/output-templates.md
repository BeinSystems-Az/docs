# Çap şablonunu tənzimləmək

Çap şablonları sənədlərin çap və çıxış görünüşünü müəyyən edir. Şablon filial və POS kassası üzrə ayrıca təyin edilə bilər.

## İstifadə qaydası

1. **Ayarlar → Sistem → Çap şablonları** səhifəsini açın və siyahıdan şablonu seçin və ya **Yeni şablon** yaradın.
2. Şablonun adını və konfiqurasiyasını tənzimləyin; önizləmə üçün **Yenilə** seçin.
3. **Kağız** ölçüsünü, **Kənar** məsafəsini, lazım olduqda **En** və **Hündürlük** dəyərlərini daxil edin.
4. **Aktiv**, **Şirkət default-u**, **Filiallar** və **POS kassaları** seçimlərini təyin edin.
5. Önizləmədə sənədin kəsilmədiyini və sahələrin düzgün göründüyünü yoxlayıb şablonu yadda saxlayın.

   > **Şəkil əlavə ediləcək —** `media/user-guide/platform/settings/output-templates/images/screen-01.png`: Şablon seçimi, kağız ölçüləri, default/filial təyinatı və önizləmə.

## Lüğət

| Termin | Bu səhifədəki mənası |
| --- | --- |
| Şablon | Çap sənədinin düzülüşü və sahələrini təyin edən konfiqurasiyadır. |
| Şirkət default-u | Digər xüsusi seçim olmadıqda tətbiq olunan standart şablondur. |
| Filial təyinatı | Şablonun istifadə ediləcəyi filialları müəyyən edir. |

## FAQ

### A5 və POS kağızı arasında nə fərq var?

Sənəd və printer formatına uyğun **Kağız** seçin; POS üçün 58mm/80mm, tam səhifə çıxışı üçün uyğun A formatı seçilə bilər.

### Şablon niyə çapda görünmür?

Şablonun aktiv olduğunu və doğru şirkət default-u, filial və ya POS kassa üçün təyin edildiyini yoxlayın.
