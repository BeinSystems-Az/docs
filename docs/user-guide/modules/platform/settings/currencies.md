# Valyuta yaratmaq

Valyuta kartı maliyyə və sənədlərdə istifadə edilən valyuta kodunu, adını, simvolunu və onluq dəqiqliyini müəyyən edir. Məzənnə tarixçəsi valyuta kartında ayrıca tabda saxlanılır.

## İstifadə qaydası

1. **Ayarlar → Maliyyə → Valyutalar** səhifəsini açıb mövcud kodu axtarın.
2. Yeni valyuta lazımdırsa **Yeni** seçin.
3. Məcburi **Valyuta Kodu**, **Valyuta Adı** və **Simvol** sahələrini doldurun.
4. **Ondalıq Mərtəbə** və **Aktiv** vəziyyətini müəyyən edib yadda saxlayın.
5. Məzənnə əlavə etmək və ya yoxlamaq üçün valyutanı açıb **Məzənnə Tarixçəsi** tabına baxın.

   > **Şəkil əlavə ediləcək —** `media/user-guide/platform/settings/currencies/images/screen-01.png`: Valyuta kodu, adı, simvolu və məzənnə tarixçəsi tabı.

## Lüğət

| Termin | Bu səhifədəki mənası |
| --- | --- |
| Valyuta kodu | Valyutanı qısa tanıdan beynəlxalq və ya daxili koddur. |
| Simvol | Məbləğin yanında göstərilən valyuta işarəsidir. |
| Ondalıq mərtəbə | Valyuta məbləğinin göstəriləcəyi onluq dəqiqlikdir. |
| Məzənnə tarixçəsi | Valyuta dəyərinin tarixlər üzrə saxlandığı qeydlərdir. |

## FAQ

### Valyuta kodu və adı olmadan saxlamaq olar?

Xeyr. **Valyuta Kodu**, **Valyuta Adı** və **Simvol** məcburidir.

### Valyuta kartı yaratmaq məzənnə yaradır?

Xeyr. Məzənnəni valyutanın **Məzənnə Tarixçəsi** tabında ayrıca qeydə alın.
