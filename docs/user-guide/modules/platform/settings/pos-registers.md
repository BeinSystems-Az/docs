# POS kassası yaratmaq

POS kassa kartı cihazı konkret anbar, pul hesabı və qəbul edilən ödəniş növləri ilə əlaqələndirir. Cihazı aktivləşdirməzdən əvvəl bu əlaqələri yoxlayın.

## İstifadə qaydası

1. **Ayarlar → Pərakəndə → Kassalar** səhifəsini açıb **Yeni** seçin.
2. Məcburi **Ad**, **Anbar** və **Hesab** sahələrini doldurun.
3. Kassada qəbul ediləcək **Ödəniş növləri**ni seçib **Aktiv** seçimini yoxlayın.
4. Kassa kartını yadda saxlayın.
5. Cihazı qoşmaq üçün kartdakı **Aktivləşdirmə kodunu yarat** əməliyyatını seçin və birdəfəlik kodu POS cihazına daxil edin.
6. Cihaz dəyişdirilirsə **Cihaz bağlantısını sıfırla** əməliyyatından əvvəl cari fiziki bağlantının silinəcəyini təsdiqləyin.

   > **Şəkil əlavə ediləcək —** `media/user-guide/platform/settings/pos-registers/images/screen-01.png`: Kassa forması, anbar/hesab/ödəniş növləri və aktivləşdirmə düymələri.

## Lüğət

| Termin | Bu səhifədəki mənası |
| --- | --- |
| POS kassa | POS cihazını ERP-də müəyyən edən kartdır. |
| Birdəfəlik aktivləşdirmə kodu | Cihazı həmin kassa kartına qoşmaq üçün müddətli istifadə edilən koddur. |
| Son bağlantı | Kassanın ERP ilə son əlaqə vaxtını göstərən məlumatdır. |

## FAQ

### Kassa yaratmaq üçün anbar və hesab vacibdir?

Bəli. **Anbar** və **Hesab** sahələri məcburidir.

### Cihaz bağlantısını sıfırlasam nə baş verir?

Mövcud fiziki cihaz bağlantısı sıfırlanır. Kassanı yenidən qoşmaq üçün yeni aktivləşdirmə kodu yaradın.
