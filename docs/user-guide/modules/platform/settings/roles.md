# Rollar

İdarəetmə menyusunda Rollar keçidi göstərilir, lakin hazırkı ERP frontend-də bu keçid üçün işlək səhifə marşrutu yoxdur. Buna görə burada rol yaratmaq və ya icazə təyin etmək addımları verilmir.

## İstifadə qaydası

**Ayarlar → İdarəetmə → Rollar** keçidini açdıqda səhifə yüklənmirsə, bu marşrutdan rol yaratmağa çalışmayın. İstifadəçi hesabının mövcud giriş və icazə idarəetmə imkanları üçün [İstifadəçilər təlimatına](../users) baxın. Bu təlimat rol idarəetmə ekranı tətbiq olunanda həmin interfeysə uyğun yenilənəcək.

## Lüğət

| Termin | Bu səhifədəki mənası |
| --- | --- |
| Rol | İstifadəçiyə verilən giriş və əməliyyat icazələri toplusudur. |
| İcazə | İstifadəçinin hansı səhifəyə daxil ola və ya hansı əməliyyatı edə biləcəyini müəyyən edən qaydadır. |

## FAQ

### Rol yarada bilərəm?

Hazırkı frontend-də menyudakı Rollar keçidinə uyğun işlək səhifə marşrutu yoxdur.

### İstifadəçinin giriş hüququnu haradan yoxlayım?

İstifadəçi siyahısındakı giriş idarəetməsi imkanlarına baxın. Tələb olunan imkan görünmürsə, administratorla əlaqə saxlayın.
