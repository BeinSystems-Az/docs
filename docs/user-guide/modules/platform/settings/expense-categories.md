# Xərc maddəsi yaratmaq

Xərc maddəsi birbaşa xərc sənədində məbləğin hansı xərc hesabında uçota alınacağını müəyyən edir.

## İstifadə qaydası

1. **Ayarlar → Maliyyə → Xərc maddələri** səhifəsini açıb **Yeni** seçin.
2. Məcburi **Kod** və **Ad** sahələrini doldurun.
3. Maddə alt qrupdursa **Üst maddə** seçin. Məcburi **Xərc hesabı** sahəsində mühasibat hesabını göstərin.
4. **Aktiv** vəziyyəti yoxlayıb yadda saxlayın.
5. **Maliyyə → Xərclər** sənədində yeni xərc maddəsinin seçilə bildiyini yoxlayın.

   > **Şəkil əlavə ediləcək —** `media/user-guide/platform/settings/expense-categories/images/screen-01.png`: Kod/ad, üst maddə və xərc hesabı.

## Lüğət

| Termin | Bu səhifədəki mənası |
| --- | --- |
| Xərc maddəsi | Xərcləri məqsəd və hesab üzrə qruplaşdıran kateqoriyadır. |
| Üst maddə | Alt xərc maddəsini daxil edən qrupdur. |
| Xərc hesabı | Maddə üzrə məbləğin mühasibat yazılışında bağlandığı hesabdır. |

## FAQ

### Xərc maddəsini xərc hesabı seçmədən yarada bilərəm?

Xeyr. **Xərc hesabı** sahəsi məcburidir.

### Xərc maddəsi xərc sənədi yaradır?

Xeyr. Bu istinad məlumatıdır; xərc sənədini **Maliyyə → Xərclər** səhifəsində ayrıca yaradın.
