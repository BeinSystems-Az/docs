# Sistem üçün ümumi ayarlar

Bu ekran **Ayarlar → Sistem → Ümumi ayarlar** yolu ilə açılır. Hazırkı frontend bu modul üçün əlavə parametr təyin olunmadığını göstərir; burada dəyişdiriləcək parametr forması yoxdur.

## İstifadə qaydası

1. Sol menyudan **Ayarlar → Sistem → Ümumi ayarlar** səhifəsini açın.
2. Ekranda “Bu modul üçün əlavə parametr təyin edilməyib” məlumatını yoxlayın.
3. Sistem modulunun faktiki sazlaması tələb olunursa, həmin məqsədə aid ayrıca menyu səhifəsinə keçin. Məsələn, POS kassaları üçün **Pərakəndə → Kassalar**, məhsul vahidləri üçün **Məhsul → Ölçü vahidləri** səhifəsindən istifadə edin.

## Lüğət

| Termin | Bu səhifədəki mənası |
| --- | --- |
| Modul ayarı | Müvafiq modul üçün konfiqurasiya parametri. |
| Parametr | Ekranda dəyişdirilə bilən və sistem davranışına təsir edən dəyər. |

## FAQ

### Səhifə niyə boş görünür?

Frontend hazırda bu modul üçün əlavə parametr olmadığını bildirir. Bu, dəyişdiriləcək ayarın olmadığı deməkdir.

### Parametr yaratmaq üçün bu səhifədə əməliyyat varmı?

Xeyr. Ekranda parametr forması və yadda saxlama əməliyyatı təqdim edilmir.
