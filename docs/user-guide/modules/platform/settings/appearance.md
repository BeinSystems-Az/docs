# Sistem görünüşünü dəyişmək

**Ayarlar → Sistem → Görünüş** səhifəsi tətbiqin rəng rejimini, rəng palitrasını və naviqasiya quruluşunu istifadəçi üçün tənzimləyir.

## İstifadə qaydası

1. Səhifədə **Görünüş modu** seçimindən **Açıq**, **Tünd** və ya **Avtomatik** variantını seçin.
2. **Tema rəngi** hissəsində palitranı seçin.
3. **Naviqasiya tipi** seçimindən **Navbar** və ya **Sidebar** görünüşünü təyin edin.
4. Dəyişikliklərin ekranda tətbiq olunduğunu yoxlayın.

   > **Şəkil əlavə ediləcək —** `media/user-guide/platform/settings/appearance/images/screen-01.png`: Görünüş modu, rəng palitrası və naviqasiya tipi.

## Lüğət

| Termin | Bu səhifədəki mənası |
| --- | --- |
| Açıq/Tünd/Avtomatik | Tətbiqin işıqlandırma rejimidir. |
| Rəng palitrası | Əsas interfeys elementlərinin rəng seçimidir. |
| Navbar/Sidebar | Əsas menyunun yuxarı zolaq və ya yan paneldə göstərilməsidir. |

## FAQ

### Dəyişiklik üçün Yadda saxla basmalıyam?

Görünüş seçimi səhifədə dərhal tətbiq edilir.

### Avtomatik rejim nə edir?

Tətbiqin görünüşünü cihaz və sistem üstünlüyünə uyğunlaşdırır.
