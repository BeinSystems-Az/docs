# POS ödəniş növü yaratmaq

POS ödəniş növü kassada istifadə edilən ödəniş üsulunu və qəbul edilən vəsaitin bağlanacağı maliyyə hesabını müəyyən edir.

## İstifadə qaydası

1. **Ayarlar → Pərakəndə → Ödəniş növləri** səhifəsini açıb **Yeni** seçin.
2. Məcburi **Ad**, **Kod** və **Hesab** sahələrini doldurun.
3. Seçimin POS-da istifadə edilməsini istəyirsinizsə **Aktiv** vəziyyətdə saxlayın.
4. Kartı yadda saxlayın və POS kassa kartında bu ödəniş növünün seçilə bildiyini yoxlayın.

   > **Şəkil əlavə ediləcək —** `media/user-guide/platform/settings/pos-payment-types/images/screen-01.png`: Ad, kod, pul hesabı və aktivlik sahələri.

## Lüğət

| Termin | Bu səhifədəki mənası |
| --- | --- |
| POS ödəniş növü | POS satışında seçilən müştəri ödəniş üsuludur. |
| Hesab | Həmin ödəniş üsulu üzrə məbləğin yazılacağı pul hesabıdır. |
| Kod | Ödəniş növünü qısa tanıdan identifikatordur. |

## FAQ

### Ödəniş növünü hesab seçmədən saxlaya bilərəm?

Xeyr. **Hesab** məcburi sahədir.

### Ödəniş növünü kassa kartına bağlamaq lazımdır?

Bəli. POS kassasında qəbul edilməli ödəniş növlərini kassa kartında seçin.
