# Əsas menyunu tənzimləmək

**Ayarlar → Sistem → Menyu** səhifəsi istifadəçilərin əsas naviqasiyasında görünən qrup və menyu elementlərini idarə edir. Menyu dəyişikliyi istifadəçinin səhifələrə çıxışına təsir edə bilər.

## İstifadə qaydası

1. Menyu ağacında redaktə edəcəyiniz qrupu və ya elementini seçin.
2. Elementin etiket və keçid sahələrini yoxlayın. Qrup yaratmaq üçün **Qrup yarat**, sıra dəyişmək üçün sürükləmə idarəsindən istifadə edin.
3. Redaktəni başladıb yeni etiketi və ya keçidi yazın; route-u dəyişirsinizsə həmin frontend səhifəsinin də mövcud olduğunu yoxlayın.
4. Dəyişikliyi tətbiq edin və menyuda yeni ad/sıranı, istifadəçi üçün açılan səhifəni yoxlayın.

   > **Şəkil əlavə ediləcək —** `media/user-guide/platform/settings/menu/images/screen-01.png`: Menyu ağacı, seçilmiş element, etiket və keçid redaktəsi.

## Lüğət

| Termin | Bu səhifədəki mənası |
| --- | --- |
| Menyu qrupu | Əlaqəli keçidlər üçün naviqasiya başlığıdır. |
| Menyu elementi | Naviqasiyada görünən səhifə və ya alt qrupdur. |
| Route | Menyu elementinin açdığı tətbiq yoludur. |

## FAQ

### Menyu elementini gizlətmək icazəni silir?

Menyu görünüşü və resurs icazələri ayrı anlayışlardır. İstifadəçi girişini ayrıca rol/icazə ekranında yoxlayın.

### İşləməyən route-u menyuya əlavə edə bilərəm?

Etməyin. Əvvəl həmin səhifənin frontend route-u olduğunu yoxlayın.
