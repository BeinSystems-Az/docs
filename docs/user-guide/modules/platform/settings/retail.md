# Pərakəndə ayarlarını idarə etmək

Pərakəndə ayarları POS əməliyyatlarının standart davranışını müəyyən edir. Səhifədə göstərilən hər parametrin izahını oxuyub yalnız təsdiqlənmiş iş qaydasına uyğun dəyişin.

## İstifadə qaydası

1. **Ayarlar → Pərakəndə → Ayarlar** səhifəsini açın.
2. Parametrləri və yanındakı izahları oxuyun; dəyişikliklərin POS satış, qəbz və kassa hesabatına təsirini müəyyən edin.
3. Lazım olan dəyərləri dəyişib **Yadda saxla** seçin.
4. POS kassa və ya ödəniş testində yeni davranışın düzgün tətbiq olunduğunu yoxlayın.

   > **Şəkil əlavə ediləcək —** `media/user-guide/platform/settings/retail/images/screen-01.png`: Pərakəndə modul ayarları və yadda saxlama düyməsi.

## Lüğət

| Termin | Bu səhifədəki mənası |
| --- | --- |
| Modul ayarı | Pərakəndə əməliyyatlarının sistem üzrə standart parametridir. |
| POS konfiqurasiyası | Kassa, anbar, hesab və ödəniş seçimlərini birləşdirən sazlamadır. |

## FAQ

### Ayarı dəyişmək üçün hansı icazə lazımdır?

Bu səhifəni redaktə etmək üçün müvafiq sazlama icazəsi tələb oluna bilər. Dəyişiklik mümkün deyilsə administratorla yoxlayın.

### Ayarı dəyişmək əvvəlki POS qəbzlərini yeniləyir?

Sazlamanı dəyişməzdən əvvəl təsir tarixini və parametr izahını yoxlayın; əvvəlki qəbzlərin yenidən hesablandığını fərz etməyin.
