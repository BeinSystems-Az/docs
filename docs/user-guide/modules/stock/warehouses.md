# Anbar yaratmaq

Anbar stok miqdarının filiala bağlı saxlanma və uçot yeridir. Anbar kartının yaradılması özlüyündə məhsul qalığı yaratmır.

## İstifadə qaydası

1. **Anbar → Konfiqurasiya → Anbarlar** səhifəsini açıb **Yeni** seçin.
2. **Filial** seçin, anbarın **Ad**ını daxil edin və sistem tələb edirsə **Kod** yazın.
3. Anbar məlumatını yadda saxlayın və siyahıda filialın, adın və kodun düzgün göründüyünü yoxlayın.
4. Bu anbarda məhsul yerləşmələrini ayrıca idarə edəcəksinizsə [Lokasiyalar](./locations) səhifəsində lokasiya yaradın.

   > **Şəkil əlavə ediləcək —** `media/user-guide/stock/warehouses/images/screen-01.png`: Anbar formasında filial, ad və kod.

## Lüğət

| Termin | Bu səhifədəki mənası |
| --- | --- |
| Anbar | Filial daxilində stok miqdarının uçot aparıldığı yerdir. |
| Filial | Anbarın aid olduğu şirkət bölməsidir. |
| Anbar kodu | Siyahıda və əməliyyatlarda anbarı qısa tanıdan koddur. |

## FAQ

### Anbar yaratmaq məhsul qalığı yaradır?

Xeyr. Qalıq anbar daxilolması, yerdəyişməsi, istehsal və digər təsdiqlənən stok sənədləri ilə dəyişir.

### Anbarı hansı filialda yaradacağımı dəyişə bilərəm?

Mövcud sənədlər və sistem qaydaları dəyişməyə məhdudiyyət qoya bilər. Kartı saxlamazdan əvvəl filialı yoxlayın.
