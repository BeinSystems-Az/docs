# Silinmə sənədi yaratmaq

Silinmə sənədi istifadəyə yararsız və ya başqa əsasla stokdan çıxarılmalı məhsul miqdarını qeydə alır. Təsdiqdən sonra seçilmiş anbarın qalığı azalır.

## İstifadə qaydası

### Silinəcək məhsulları daxil edin

1. **Anbar → Silinmələr** səhifəsini açın və **Yeni** seçin.
2. **Tarix** və **Anbar** sahələrini doldurun.
3. **Məhsullar** tabında məhsulu, silinəcək miqdarı və vahidi seçin. Lot/seriya ilə izlənən məhsuldursa uyğun partiyanı göstərin.
4. **Qeyd** sahəsində silinmə səbəbini yazın.

   > **Şəkil əlavə ediləcək —** `media/user-guide/stock/scrap/images/screen-01.png`: Anbar seçimi, məhsul/miqdar sətri və silinmə səbəbi.

### Silinməni təsdiqləyin

5. Məhsul və miqdarın faktiki silinməyə uyğun olduğunu yoxlayıb sənədi yadda saxlayın.
6. **Təsdiq** əməliyyatını seçin. Məhsulun qalığının azaldığını **Anbar qalığı** hesabatında yoxlayın.

   > **Video əlavə ediləcək —** `media/user-guide/stock/scrap/videos/walkthrough-01.mp4`: Silinmə səbəbini qeyd etmək və sənədi təsdiqləmək.

## Lüğət

| Termin | Bu səhifədəki mənası |
| --- | --- |
| Silinmə | Məhsul miqdarını stokdan çıxaran sənəddir. |
| Silinmə səbəbi | Məhsulun hansı əsasla stokdan çıxarıldığını izah edən qeyddir. |
| Lot / seriya | Silinən partiya və ya məhsul vahidinin izləmə nömrəsidir. |

## FAQ

### Silinmə səbəbini harada yazım?

Sənəddəki **Qeyd** sahəsindən istifadə edin.

### Sənədi yadda saxlamaq qalığı azaldır?

Stok nəticəsi **Təsdiq** addımında tətbiq olunur. Qaralama saxlanması qalığı dəyişmir.
