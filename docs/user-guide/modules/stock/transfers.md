# Anbarlararası yerdəyişmə yaratmaq

Yerdəyişmə sənədi məhsul stokunu bir anbardan digərinə köçürür. Şirkət üzrə ümumi miqdar dəyişmir; mənbə anbarın qalığı azalır, təyinat anbarın qalığı artır.

## İstifadə qaydası

### Mənbə və təyinat anbarlarını seçin

1. **Anbar → Yerdəyişmələr** səhifəsini açın və **Yeni** seçin.
2. **Anbardan** sahəsində mənbə, **Anbara** sahəsində təyinat anbarını seçin. Bu iki anbar fərqli olmalıdır.
3. Sənədin tarixini və lazım olduqda nömrəsini daxil edin.

### Köçürüləcək məhsulları göstərin

4. **Məhsullar** tabında məhsul, miqdar, vahid və varsa lot/seriya seçin. Lokasiya uçotu göstərilirsə mənbə və təyinat lokasiyalarını yoxlayın.
5. **Qeyd** sahəsinə köçürmənin məqsədini daxil edib sənədi yadda saxlayın.

   > **Şəkil əlavə ediləcək —** `media/user-guide/stock/transfers/images/screen-01.png`: Mənbə və təyinat anbarları və köçürülən məhsul sətri.

### Yerdəyişməni təsdiqləyin

6. Mənbə/təyinat anbarlarını və miqdarları yoxladıqdan sonra **Təsdiq** seçin.
7. **Anbar qalığı** hesabatında hər iki anbarı ayrıca seçin: mənbədə azalma, təyinatda artım görünməlidir.

   > **Video əlavə ediləcək —** `media/user-guide/stock/transfers/videos/walkthrough-01.mp4`: İki anbar arasında məhsul köçürmək və hər iki qalığı tutuşdurmaq.

## Lüğət

| Termin | Bu səhifədəki mənası |
| --- | --- |
| Mənbə anbar | Məhsulun çıxacağı ilkin anbardır. |
| Təyinat anbar | Məhsulun daxil olacağı anbardır. |
| Yerdəyişmə | Şirkət daxilində stokun anbarlar arasında köçürülməsidir. |

## FAQ

### Yerdəyişmə ümumi stok miqdarını dəyişir?

Xeyr. Eyni məhsul miqdarı bir anbardan çıxır və digərinə daxil olur.

### Eyni anbarı hər iki sahədə seçmək olar?

Xeyr. Mənbə və təyinat üçün müxtəlif anbarlar seçin.
