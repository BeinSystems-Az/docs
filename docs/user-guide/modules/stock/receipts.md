# Daxilolma sənədi yaratmaq

Daxilolma sənədi məhsul miqdarını seçilmiş anbarın qalığına artırır. Bu sənəd alış fakturasını əvəz etmir; onun əsas məqsədi stok qəbulunu qeydə almaqdır.

## İstifadə qaydası

### Daxilolma yaradın

1. **Anbar → Daxilolmalar** səhifəsini açın və **Yeni** seçin.
2. Sənədin **Tarix** və **Anbar** sahələrini doldurun. **Nömrə**ni özünüz verə və ya sistemin yaratdığı nömrəni saxlaya bilərsiniz.
3. **Məhsullar** tabında məhsul sətri əlavə edin. Məhsulu, miqdarı, vahidi və lazım olduqda **Lot / seriya** seçimini göstərin. **Maya dəyəri** sahəsini sənəd üçün tələb olunursa daxil edin.
4. **Qeyd** sahəsində qəbul haqqında daxili izahı yazın. **Miqdar** və **Məbləğ** cəmləri sətirlərdən hesablanır.

   > **Şəkil əlavə ediləcək —** `media/user-guide/stock/receipts/images/screen-01.png`: Daxilolma formasında tarix, anbar və məhsul sətri.

### Sənədi təsdiqləyin

5. Sətirlərdəki məhsul, miqdar, vahid və lot/seriyanı faktiki qəbul ilə tutuşdurun.
6. Sənədi yadda saxlayın. Stok nəticəsini tətbiq etmək üçün sənədi **Təsdiq** edin.
7. **Anbar → Anbar Hesabatları → Anbar qalığı** səhifəsində həmin anbar və məhsulun yeni miqdarını yoxlayın.

   > **Video əlavə ediləcək —** `media/user-guide/stock/receipts/videos/walkthrough-01.mp4`: Daxilolma sənədi açmaq, məhsul sətri daxil etmək, təsdiqləmək və qalığı yoxlamaq.

## Lüğət

| Daxilolma | Məhsulu seçilmiş anbara əlavə edən stok sənədidir. |

## FAQ

### Daxilolmanı saxlamaq stok qalığını artırır?

Qalıq təsdiq addımında tətbiq olunur. Qaralama saxlanması özlüyündə anbar stokunu artırmır.

### Daxilolma sənədi təchizatçı borcu yaradır?

Bu sənəd stok qəbulunu qeyd edir. Təchizatçı hesablaşması üçün **Təchizat → Fakturalar** səhifəsində alış fakturası ilə işləyin.
