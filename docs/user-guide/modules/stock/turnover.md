# Anbar dövriyyəsinə baxmaq

Anbar dövriyyəsi seçilmiş dövrdə məhsula aid daxilolma və çıxış miqdarlarını göstərir. Məhsul sətrini açmaqla hərəkət tarixçəsinə və onu yaradan stok qeydlərinə baxa bilərsiniz.

## İstifadə qaydası

1. **Anbar → Anbar Hesabatları → Anbar Dövriyyəsi** səhifəsini açın.
2. Hesabatda mövcud olan dövr, anbar və məhsul filtrlərini seçin.
3. Nəticəni yenilədikdən sonra giriş, çıxış və dövr sonu miqdarını müqayisə edin.
4. Məhsul sətrini seçərək **Hərəkət tarixçəsi** panelini açın. Tarixçədəki hərəkətləri daxilolma və çıxış sənədləri ilə yoxlayın.

   > **Şəkil əlavə ediləcək —** `media/user-guide/stock/turnover/images/screen-01.png`: Dövr üzrə giriş/çıxış göstəriciləri və açılan stok tarixçəsi.

## Lüğət

| Termin | Bu səhifədəki mənası |
| --- | --- |
| Dövriyyə | Dövr ərzində qeydə alınmış stok giriş və çıxışlarının cəmidir. |
| Hərəkət tarixçəsi | Məhsulun stok miqdarını dəyişən sənədlərin zaman sırasıdır. |

## FAQ

### Məhsul sətrindən mənbə sənədi tapa bilərəm?

Sətri seçib açılan hərəkət tarixçəsində müvafiq əməliyyat qeydlərinə baxın. Keçid mövcuddursa, mənbə sənədi oradan açılır.

### Dövriyyə mənfi görünə bilər?

Dövr filtrlərini və çıxış hərəkətlərini yoxlayın. Mənfi qalıq görünürsə, ilkin stok və təsdiqlənmiş hərəkətlərin ardıcıllığını araşdırın.
