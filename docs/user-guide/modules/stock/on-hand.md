# Anbar qalığına baxmaq

Anbar qalığı səhifəsi seçilmiş hesabat görünüşündə məhsulların mövcud miqdarını göstərir. Məhsul sətrini seçərək onun tarix üzrə stok hərəkətini araşdırmaq mümkündür.

## İstifadə qaydası

1. **Anbar → Anbar Hesabatları → Anbar qalığı** səhifəsini açın.
2. Səhifədəki tablardan baxış məqsədinə uyğun görünüşü seçin. Filial, anbar və tarix filtrləri varsa, hesabatı daraltmaq üçün seçin və tətbiq edin.
3. Məhsul sətrindəki miqdarı yoxlayın. Sətri açmaq mümkündürsə, **Hərəkət tarixçəsi** panelində ilkin qalıq, giriş, çıxış və son qalığı tutuşdurun.
4. Nəticədə fərq varsa, həmin dövrün təsdiqlənmiş daxilolma, çıxış, yerdəyişmə və inventarizasiya sənədlərini yoxlayın.

   > **Şəkil əlavə ediləcək —** `media/user-guide/stock/on-hand/images/screen-01.png`: Anbar qalığı hesabatının filtr və məhsul sətirləri; açılmış hərəkət tarixçəsi.

## Lüğət

| Termin | Bu səhifədəki mənası |
| --- | --- |
| Anbar qalığı | Seçilmiş anbarda hesabat vaxtına mövcud məhsul miqdarıdır. |
| İlkin qalıq | Seçilmiş dövrün əvvəlində qeydə alınmış miqdardır. |
| Hərəkət tarixçəsi | Məhsula aid giriş və çıxış əməliyyatlarının ardıcıllığıdır. |

## FAQ

### Hesabatdakı qalıq gözlədiyimdən fərqlidirsə nəyi yoxlayım?

Filial, anbar və tarix filtrlərini yoxlayın, sonra həmin dövrdə təsdiqlənmiş stok sənədlərini və lot/seriya seçimini tutuşdurun.

### Hesabat qalığı özü düzəldirmi?

Xeyr. Hesabat məlumatı göstərir. Düzəliş tələb olunursa inventarizasiya sənədi ilə faktiki sayımı qeydə alın.
