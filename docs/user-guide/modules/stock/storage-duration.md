# Stokun saxlanma müddətinə baxmaq

Stokun saxlanma müddəti hesabatı məhsulun anbarda qalma müddətini və müvafiq stok qeydlərini təhlil etməyə kömək edir.

## İstifadə qaydası

1. **Anbar → Anbar Hesabatları → Stokun saxlanma müddəti** səhifəsini açın.
2. Filial, anbar, məhsul və hesabat üçün görünən tarix filtrlərini seçib nəticəni yeniləyin.
3. Məhsul sətirlərində göstərilən stok yaşı və miqdar göstəricilərini müqayisə edin.
4. Uzun müddət anbarda qalan məhsulu yoxlamaq üçün sətri və ya məhsulun tarixçəsini açın; alış və stok daxilolma tarixlərini ilkin sənədlərlə tutuşdurun.

   > **Şəkil əlavə ediləcək —** `media/user-guide/stock/storage-duration/images/screen-01.png`: Filtr tətbiq edilmiş hesabat və uzun müddət qalmış məhsul sətri.

## Lüğət

| Termin | Bu səhifədəki mənası |
| --- | --- |
| Saxlanma müddəti | Məhsulun və ya stok partiyasının anbarda qaldığı vaxtdır. |
| Stok partiyası | Müəyyən daxilolma və ya partiya ilə izlənən məhsul miqdarıdır. |

## FAQ

### Hesabatdakı müddət hansı tarixdən hesablanır?

Hesabatın tarix filtrlərini və sətrin göstərdiyi stok qəbul tarixini yoxlayın. Daxilolma sənədi ilə müqayisə edin.

### Bu hesabatdan məhsulu silmək olar?

Xeyr. Hesabat təhlil üçündür; stokdan çıxarmaq üçün **Silinmələr** sənədindən istifadə edin.
