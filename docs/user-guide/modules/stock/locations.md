# Anbar lokasiyası yaratmaq

Lokasiya anbarda məhsulun fiziki saxlandığı yeri göstərir. Lokasiyalar sənəd sətirlərində seçilərsə, stok hərəkətini anbar daxilində də izləməyə kömək edir.

## İstifadə qaydası

1. **Anbar → Konfiqurasiya → Lokasiyalar** səhifəsini açıb **Yeni** seçin.
2. Lokasiyanın **Ad**ını və sistem tələb edirsə **Kod**unu yazın.
3. Lokasiyanın aid olduğu **Anbar**ı seçin. Forma əlavə olaraq üst lokasiya və ya növ göstərirsə, mövcud fiziki quruluşunuza uyğun dəyəri seçin.
4. Lokasiyanı yadda saxlayın və siyahıdan anbara düzgün bağlandığını yoxlayın.

   > **Şəkil əlavə ediləcək —** `media/user-guide/stock/locations/images/screen-01.png`: Lokasiya formasında ad, kod və ona bağlı anbar seçimi.

## Lüğət

| Termin | Bu səhifədəki mənası |
| --- | --- |
| Lokasiya | Anbar daxilində məhsulun saxlanma nöqtəsidir. |
| Üst lokasiya | Daha böyük saxlama zonasının daxilində olan alt yerdir. |

## FAQ

### Lokasiyanı anbardan ayrı yaratmaq olar?

Lokasiya müvafiq anbara bağlanmalıdır. Əvvəl **Anbarlar** səhifəsində anbar yaradın və ya mövcud anbarı seçin.

### Lokasiya yaratmaq stok miqdarını dəyişir?

Xeyr. Lokasiya saxlama strukturudur; miqdar stok sənədlərinin təsdiqi ilə dəyişir.
