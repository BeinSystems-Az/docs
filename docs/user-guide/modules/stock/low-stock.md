# Minimum qalıq hesabatına baxmaq

Minimum qalıq hesabatı aşağı stok həddinə çatmış məhsulları tapmağa kömək edir. Hesabat sifariş və ya satınalma sənədi yaratmır.

## İstifadə qaydası

1. **Anbar → Anbar Hesabatları → Minimum Qalıq** səhifəsini açın.
2. Filial və anbar filtrlərini seçin, sonra nəticəni yeniləyin.
3. Hesabatda qalıq miqdarını məhsul üçün təyin edilmiş minimum göstərici ilə müqayisə edin.
4. Yenidən tədarük lazımdırsa məhsul və tələb olunan miqdarı müəyyən edin; sonra **Təchizat → Sifarişlər** səhifəsində alış sifarişi yaradın.

   > **Şəkil əlavə ediləcək —** `media/user-guide/stock/low-stock/images/screen-01.png`: Minimum həddən aşağı məhsulların siyahısı və qalıq göstəriciləri.

## Lüğət

| Termin | Bu səhifədəki mənası |
| --- | --- |
| Minimum qalıq | Yenidən tədarükü nəzərdən keçirmək üçün məhsula təyin edilən miqdar həddidir. |
| Tədarük | Stoku artırmaq üçün təchizatçıdan məhsul əldə etmək prosesidir. |

## FAQ

### Hesabat aşağı miqdarlı məhsul üçün sifariş yaradır?

Xeyr. Hesabat xəbərdarlıq siyahısıdır; sifarişi istifadəçi ayrıca yaradır.

### Məhsul hesabatda görünmürsə nəyi yoxlayım?

Məhsulun minimum qalıq göstəricisini və seçilmiş filial/anbar filtrlərini yoxlayın.
