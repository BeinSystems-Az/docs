# Anbar inventarizasiyası aparmaq

İnventarizasiya seçilmiş anbardakı sistem qalığını fiziki sayımla müqayisə edir. Sənəd məhsul sətirlərində nəzəri miqdarı və sayılmış miqdarı göstərir, təsdiq zamanı fərqi stok uçotuna tətbiq edir.

## İstifadə qaydası

### İnventarizasiya sənədi yaradın

1. **Anbar → İnventarizasiyalar** səhifəsini açın və **Yeni** seçin.
2. **Tarix** və sayım aparılan **Anbar**ı göstərin.
3. **Məhsullar** tabına inventarizasiya olunacaq məhsulları əlavə edin. Hər sətirdə sistemin göstərdiyi **Sistem miqdarı**nı fiziki sayımla müqayisə edin və **Sayılmış miqdar** daxil edin.
4. Lot/seriya ilə izlənən məhsullar üçün uyğun lot/seriya sətrini yoxlayın. **Qeyd** sahəsində sayım əhatəsini və qeydləri yazın.

   > **Şəkil əlavə ediləcək —** `media/user-guide/stock/inventory/images/screen-01.png`: Sistem miqdarı və sayılmış miqdar sütunları olan sayım sətirləri.

### Fərqi yoxlayıb təsdiqləyin

5. Sayım yekunlaşdıqdan sonra hər sətirdə sistem və fiziki miqdarın düzgün olduğunu yoxlayın.
6. Sənədi yadda saxlayın, sayım nəticəsi təsdiqləndikdən sonra **Təsdiq** edin.
7. **Anbar qalığı** hesabatında yeni miqdarı yoxlayın.

   > **Video əlavə ediləcək —** `media/user-guide/stock/inventory/videos/walkthrough-01.mp4`: İnventarizasiya sətri əlavə etmək, fiziki sayımı yazmaq və fərqi təsdiqləmək.

## Lüğət

| Termin | Bu səhifədəki mənası |
| --- | --- |
| Sistem miqdarı | Sənəd yaranarkən anbarda uçota alınan nəzəri məhsul miqdarıdır. |
| Sayılmış miqdar | Fiziki sayım zamanı müəyyən edilən faktiki miqdardır. |
| Sayım fərqi | Sayılmış miqdarla sistem miqdarı arasındakı fərqdir. |

## FAQ

### Sayılmış miqdarı boş saxlasam nə baş verir?

Sayım nəticəsini təsdiq etməzdən əvvəl sayımda olan hər məhsulun faktiki miqdarını daxil edin.

### İnventarizasiya sənədini yadda saxlamaq qalığı düzəldir?

Xeyr. Sayım fərqinin stoka tətbiqi sənəd təsdiq ediləndə baş verir.
