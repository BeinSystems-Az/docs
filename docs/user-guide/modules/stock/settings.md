# Anbar ayarlarını tənzimləmək

Anbar ayarları rezervasiya qaydasını, mənfi stok imkanını, minimum qalıq xəbərdarlığını və maya dəyəri metodunu müəyyən edir. Maya dəyəri metodundakı dəyişiklik yalnız bundan sonra təsdiqlənən stok hərəkətlərinə tətbiq olunur.

## İstifadə qaydası

1. **Ayarlar → Anbar → Ayarlar** səhifəsini açın.
2. **Maya dəyəri metodu** sahəsində **AVCO**, **FIFO** və ya **Standard** seçin.
3. **Stok Rezervasiyası** bölməsində avtomatik rezerv və sərbəst stok davranışı üçün göstərilən seçimləri oxuyun.
4. **Minimum qalıq xəbərdarlığı limiti**nə xəbərdarlıq həddini daxil edin. **Mənfi stok** seçimi varsa, çatışmayan qalıqla çıxışın mümkün olub-olmadığını diqqətlə müəyyən edin.
5. **Yadda saxla** seçin. Təsdiq olunmuş yeni stok hərəkətində maya dəyəri metodunun necə tətbiq olunduğunu yoxlayın.

   > **Şəkil əlavə ediləcək —** `media/user-guide/stock/settings/images/screen-01.png`: Maya metodu, rezervasiya, mənfi stok və minimum xəbərdarlıq limitləri.

## Lüğət

| Termin | Bu səhifədəki mənası |
| --- | --- |
| AVCO | Orta çəkili maya dəyəri üsuludur. |
| FIFO | İlk daxil olan stokun ilk çıxması yanaşmasıdır. |
| Minimum qalıq həddi | Məhsul qalığı aşağı düşəndə xəbərdarlıq üçün istifadə olunan limitdir. |
| Mənfi stok | Mövcud qalıq kifayət etmədikdə çıxışa icazə verən parametrdir. |

## FAQ

### Maya dəyəri metodunu dəyişmək əvvəlki sənədləri yenidən hesablayır?

Xeyr. Ekran xəbərdarlığına görə dəyişiklik yalnız bundan sonra təsdiqlənən stok hərəkətlərinə tətbiq olunur.

### Mənfi stok seçimi serial məhsullara da tətbiq olunur?

Xeyr. Ekranda serial izlənən məhsulların bu qaydadan istisna olduğu bildirilir.
