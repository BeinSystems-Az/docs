# Rezervləri izləmək

Rezerv satış sifarişi üçün ayrılmış stok miqdarını göstərir. Rezerv anbardakı fiziki qalığı dəyişmir, amma digər sifarişlərin istifadə edə biləcəyi miqdara təsir edə bilər.

## İstifadə qaydası

### Rezerv siyahısını yoxlayın

1. **Anbar → Anbar Hesabatları → Rezervlər** bölməsini açın.

   > **Şəkil əlavə ediləcək —** `media/user-guide/stock/reservations/images/screen-01.png`: Rezerv siyahısında satış sifarişi, müştəri, məhsul, anbar, tələb/rezerv miqdarı və status sütunları.

2. Siyahıda **Gözləyir**, **Qismən rezerv edilib**, **Rezerv edilib** və ya istifadə edilmiş vəziyyətlərə diqqət edin. **Tələb olunan**, **Rezerv edilib**, **Gözləyir** və **İstifadə edilib** miqdarlarını müqayisə edin.

### Rezervi yenidən hesablayın və ya buraxın

3. Gözləyən və ya qismən rezerv sətrini açın. Anbar seçiminin və satış sifarişinin düzgün olduğunu təsdiqləyin.

4. Mövcud stok uyğun hala gəldikdə **Yenidən rezerv et** əməliyyatını seçin və status/miqdarın yeniləndiyini yoxlayın. Sifariş artıq yerinə yetirilməyəcəksə və ya rezerv ləğv olunmalıdırsa **Rezervi burax** əməliyyatından istifadə edin.

5. Rezerv əməliyyatından sonra əlaqəli satış sifarişini və anbardakı mövcud miqdarı yenidən yoxlayın.

## Lüğət

| Termin | Bu səhifədəki mənası |
| --- | --- |
| Tələb olunan | Satış sifarişinin tələb etdiyi məhsul miqdarıdır. |
| Rezerv edilib | Sifariş üçün ayrılmış miqdardır. |
| Gözləyir | Mövcud stok çatmadığı üçün hələ ayrılmamış miqdardır. |
| İstifadə edilib | Sonrakı sənəddə satış üçün sərf olunmuş rezerv miqdarıdır. |

## FAQ

### Rezerv yaratmaq anbar qalığını azaldırmı?

Fiziki anbar qalığı dəyişmir. Rezerv başqa sifariş üçün istifadə edilə bilən miqdarı azalda bilər.

### Rezerv niyə qisməndir?

Sifarişin bütün tələbini qarşılamaq üçün anbar stokunda kifayət qədər sərbəst miqdar olmaya bilər. Məhsul və anbar məlumatını yoxlayın.

### Rezervi buraxmaq sifarişi silirmi?

Xeyr. **Rezervi burax** ayrılmış miqdarı azad edir; əlaqəli satış sifarişi ayrıca qalır.
