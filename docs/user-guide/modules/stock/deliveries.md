# Çıxış sənədi yaratmaq

Çıxış sənədi məhsulu seçilmiş anbardan azaldır. Müştəriyə faktiki təhvil və anbar stokunun çıxışını qeydə almaq üçün istifadə olunur.

## İstifadə qaydası

### Çıxış sənədi yaradın

1. **Anbar → Çıxışlar** səhifəsini açın və **Yeni** seçin.
2. **Tarix** və **Anbar** sahələrini doldurun. Müştəri məlumdursa **Müştəri** seçin; bu sahə formanıza görə boş qala bilər.
3. **Məhsullar** tabında çıxarılan məhsulu, miqdarı, vahidi və tələb olunursa lot/seriyanı seçin. Mövcud qalıq, rezerv və sərbəst miqdar göstəricilərini yoxlayın.
4. **Qeyd** sahəsinə təhvil və ya çıxışın səbəbini yazın.

   > **Şəkil əlavə ediləcək —** `media/user-guide/stock/deliveries/images/screen-01.png`: Anbar, müştəri və məhsul sətiri olan çıxış forması.

### Çıxışı təsdiqləyin

5. Məhsul miqdarını faktiki təhvil verilən sayla tutuşdurun və sənədi yadda saxlayın.
6. **Təsdiq** əməliyyatını seçin. Sonra **Anbar qalığı** hesabatında müvafiq məhsulun azalmasını yoxlayın.
7. Maliyyə satışını ayrıca rəsmiləşdirmək lazımdırsa **Satış → Satışlar** səhifəsində satış sənədini yoxlayın; çıxış sənədini faktura kimi qəbul etməyin.

   > **Video əlavə ediləcək —** `media/user-guide/stock/deliveries/videos/walkthrough-01.mp4`: Məhsulun anbardan çıxışını yaratmaq, təsdiqləmək və stok qalığını yoxlamaq.

## FAQ

### Çıxış sənədi satış fakturası yaradır?

Xeyr. Çıxış sənədi stok hərəkətidir; satış fakturası və hesablaşmanı ayrıca satış axınında rəsmiləşdirin.

### Çıxış miqdarı sərbəst qalıqdan çox ola bilər?

Məhsul üzrə göstərilən qalıq və rezerv miqdarını yoxlayın. Sistem mövcudluq məhdudiyyəti tətbiq etdikdə uyğun miqdarı daxil edin və ya əvvəlcə stok daxilolmasını tamamlayın.
