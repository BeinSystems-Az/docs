# Təchizatçıya alış qaytarması yaratmaq

Alış qaytarması təchizatçıya geri göndərilən məhsul və hesablaşma məbləğini qeydə alır. Qaytarmanı təsdiqləməzdən əvvəl mənbə alış sənədini, anbarı və qaytarılan faktiki miqdarı yoxlayın.

## İstifadə qaydası

### Qaytarma sənədini yaradın

1. Sol menyudan **Təchizat → Qaytarmalar** bölməsini açın.

   > **Şəkil əlavə ediləcək —** `media/user-guide/purchase/purchase-returns/images/screen-01.png`: Təchizat menyusunda Qaytarmalar seçimi və sənəd siyahısı.

2. Siyahının yuxarısındakı **Yeni** düyməsini seçin. Əgər alış sənədindən qaytarma yaradırsınızsa, həmin sənəddəki **Sənəd yarat → Alış qaytarması** menyusundan başlayın.

### Təchizatçı və qaytarılan məhsulları göstərin

3. **Təchizatçı**, **Anbar** və **Valyuta** sahələrini seçin. Tarix, filial, layihə və mənbə alış sənədi məlumatlarını yoxlayın.

4. **Məhsullar** səhifəsində geri qaytarılan məhsulları əlavə edin. Yalnız faktiki göndərilən miqdarı yazın; məhsulun qiyməti və vergi məlumatını mənbə alış sənədi ilə müqayisə edin.

   > **Şəkil əlavə ediləcək —** `media/user-guide/purchase/purchase-returns/images/screen-02.png`: Təchizatçı, anbar və məhsul sətrində geri qaytarılan miqdar görünür.

5. Sənədin endirimini, vergisini və yekun məbləğini yoxlayın. Mühasibatlıq modulu aktivdirsə **Müxabirləşmə** səhifəsində maliyyə təsirinə baxın.

### Qaytarmanı təsdiqləyin

6. Məlumatlar düzgün olduqda **Təsdiq** düyməsini seçin. Qaytarılan məhsulun anbardakı qalığının azaldığını və təchizatçı ilə hesablaşma nəticəsini yoxlayın.

   > **Video əlavə ediləcək —** `media/user-guide/purchase/purchase-returns/videos/walkthrough-01.mp4`: Alış sənədindən qaytarma yaradılması, miqdarın daxil edilməsi, təsdiq və nəticənin yoxlanması.

## FAQ

### Alış qaytarması təsdiqlənəndə nə baş verir?

Qaytarma anbar qalığını azaldır və hesablaşma/mühasibat nəticəsi yarada bilər. Dəqiq maliyyə nəticəsi aktiv modul və hesab sazlamalarından asılıdır.

### Qaytarmanı mənbə alış sənədindən yaratmalıyam?

Mümkündürsə, mənbə alış sənədindəki **Sənəd yarat → Alış qaytarması** əməliyyatından başlayın. Bu, əsas məlumatların köçürülməsinə kömək edir; yenə də faktiki qaytarma miqdarını yoxlayın.

### Eyni məhsulun hamısını qaytarmaq məcburidirmi?

Xeyr. Sənəd sətrində geri göndərilən faktiki miqdarı göstərin.
