# Alış fakturasını qeydiyyata almaq

Alış fakturası təchizatçının hesabladığı məbləği, vergi və ödəniş tarixlərini qeydə alır. Fakturanı təsdiqləmək özü mal qəbulu yaratmır; fiziki stok üçün **Alış sənədi** istifadə olunur.

## İstifadə qaydası

### Faktura formasını açın

1. Sol menyudan **Təchizat → Fakturalar** bölməsinə keçin.

   > **Şəkil əlavə ediləcək —** `media/user-guide/purchase/purchase-invoices/images/screen-01.png`: Təchizat menyusunda Fakturalar seçimi və faktura siyahısı.

2. Faktura siyahısında **Yeni** düyməsini seçin. Alış sifarişindən başlayırsınızsa, həmin sifarişdəki **Sənəd yarat → Alış fakturası** əməliyyatını seçin; yaranan sətir və təchizatçı məlumatlarını tutuşdurun.

### Təchizatçı və faktura sətirlərini daxil edin

3. Başlıqda **Təchizatçı**, **Valyuta** və **Anbar** sahələrini seçin. Fakturanın tarixini, təchizatçının sənəd nömrəsini, son ödəniş tarixini, filialı və layihəni mövcud sahələrdə qeyd edin.

4. **Məhsullar** səhifəsində fakturadakı məhsul sətirlərini daxil edin. Məhsul, miqdar, vahid qiymət, endirim və vergi məlumatlarını təchizatçının ilkin sənədi ilə müqayisə edin.

   > **Şəkil əlavə ediləcək —** `media/user-guide/purchase/purchase-invoices/images/screen-02.png`: Təchizatçı fakturasındakı məhsul sətirləri sistemdə daxil edilmiş, vergi və yekun məbləğlərlə tutuşdurulan forma.

5. Hesablanmış məbləğ və ƏDV-ni faktura ilə yoxlayın. Mühasibatlıq modulu aktivdirsə **Müxabirləşmə** səhifəsində təklif olunan hesabları və nəticəni gözdən keçirin.

### Fakturanı təsdiqləyin

6. Məlumatlar uyğun olduqda **Təsdiq** düyməsini seçin. Faktura siyahısında statusu və təchizatçı borcunun dəyişməsini **Borclar** bölməsində yoxlayın.

7. Fakturadan ayrıca mal qəbulu lazımdırsa **Sənəd yarat → Alış sənədi** seçin və real qəbul edilən miqdarları həmin sənəddə təsdiqləyin.

   > **Video əlavə ediləcək —** `media/user-guide/purchase/purchase-invoices/videos/walkthrough-01.mp4`: Alış fakturasının yaradılması, sətirlərin daxil edilməsi, təsdiqlənməsi və borc nəticəsinin yoxlanması.

## Lüğət

| Termin | Bu səhifədəki mənası |
| --- | --- |
| Alış fakturası | Təchizatçının təqdim etdiyi məbləğ və hesablaşma məlumatlarını qeydə alan maliyyə sənədidir. |

## FAQ

### Alış fakturasını təsdiqləyəndə stok artırmı?

Faktura maliyyə borcunu və vergi/mühasibat nəticəsini qeydə alır. Fiziki qəbul üçün **Alış sənədi** yaradıb təsdiqləyin.

### Faktura alış sənədindən yarana bilərmi?

Bəli. Mənbə sənədində **Sənəd yarat** menyusu varsa, oradan **Alış fakturası** seçin və köçürülən məlumatları yoxlayın.

### Faktura üzrə ödənişi harada daxil edirəm?

**Ödənişlər** bölməsindən müvafiq təchizatçı borcuna ödəniş yaradın və hesablaşmanın düzgün tərəfdaşa bağlandığını yoxlayın.
