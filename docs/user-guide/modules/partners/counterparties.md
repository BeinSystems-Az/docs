# Tərəf-müqabil kartını yaratmaq

**Bütün tərəf-müqabillər** səhifəsi ümumi tərəfdaş reyestridir. Buradan fiziki şəxs və ya şirkət kartı yarada, onun müştəri və təchizatçı rollarını təyin edə bilərsiniz.

## İstifadə qaydası

### Ümumi tərəf-müqabillər siyahısında kart açın

1. **Tərəf-müqabillər → Bütün tərəf-müqabillər** səhifəsini açın.
2. **Yeni** seçin və tərəfdaş kartının əsas məlumatlarını daxil edin.
3. **Ad** sahəsini doldurun. Təşkilat kartıdırsa şirkət statusunu aktiv edin; fiziki şəxsdirsə uyğun şəxsi məlumatları daxil edin.
4. Telefon, e-poçt, VÖEN və ünvan sahələrini tərəfdaşın təqdim etdiyi məlumatla tamamlayın.

   > **Şəkil əlavə ediləcək —** `media/user-guide/partners/counterparties/images/screen-01.png`: Ümumi tərəf-müqabillər siyahısı və yeni kart açmaq düyməsi.

### Tərəfdaşın rol və əlaqə məlumatını saxlayın

5. Kart alışda istifadə olunacaqsa **Təchizatçı**, satışda istifadə olunacaqsa **Müştəri** rolunu aktiv edin. Hər iki məqsəd varsa hər iki rolu seçin.
6. Müştəri üçün uyğun **Qiymət növü** təyin edilə bilər. ƏDV və mühasibat hesabı sahələrini şirkətinizin uçot qaydasına əsasən doldurun.
7. Bank məlumatı saxlanacaqsa **Bank hesabları** hissəsinə keçib hesab sahibini və rekvizitləri yoxlayın.
8. **Yadda saxla** seçin. Kartı ümumi tərəf-müqabillər siyahısında tapıb, roluna uyğun alış və ya satış səhifəsində seçilə bildiyini yoxlayın.

   > **Video əlavə ediləcək —** `media/user-guide/partners/counterparties/videos/walkthrough-01.mp4`: Ümumi siyahıdan tərəfdaş kartı açmaq, əlaqə məlumatları ilə müştəri/təchizatçı rolunu daxil etmək və kartı saxlamaq.

## Lüğət

| Termin | Bu səhifədəki mənası |
| --- | --- |
| Tərəf-müqabil | Şirkətin alış, satış və digər işgüzar əlaqə saxladığı şəxs və ya şirkətdir. |
| Müştəri rolu | Tərəfdaşı satış sənədlərində alıcı kimi seçməyə imkan verən roldur. |
| Təchizatçı rolu | Tərəfdaşı alış sənədlərində satıcı kimi seçməyə imkan verən roldur. |
| Qiymət növü | Müştəriyə təklif olunan satış qiymətinin hansı qaydadan götürüləcəyini müəyyən edir. |

## FAQ

### Eyni kart həm müştəri, həm də təchizatçı ola bilər?

Bəli. Kartda hər iki rolu aktiv edin; eyni tərəfdaş üçün ikinci kart yaratmağa ehtiyac yoxdur.

### Tərəfdaş kartı yaratmaq alış və ya satış sənədi yaradır?

Xeyr. Kart reyestr məlumatıdır. Alış və satış sənədləri uyğun modullarda ayrıca yaradılır.

### Müştəri və təchizatçılar üçün ayrıca siyahı varmı?

Bəli. **Satış → Müştərilər** və **Təchizat → Təchizatçılar** həmin rollara görə siyahı göstərir. Bu səhifə bütün tərəfdaşların ümumi reyestridir.
