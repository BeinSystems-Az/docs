# Müştəri kartından istifadə etmək

**Satış → Müştərilər** siyahısı satış sənədlərində alıcı kimi seçilən tərəf-müqabilləri göstərir. Müştəri kartında əlaqə və hesablaşma məlumatlarını satışdan əvvəl dəqiqləşdirin.

## İstifadə qaydası

1. **Satış → Müştərilər** səhifəsini açıb alıcını axtarın.
2. Kart yoxdursa **Yeni** seçin, ad, əlaqə və tələb olunan vergi məlumatlarını daxil edin.
3. **Müştəri** rolunu aktiv edin. Tətbiq olunursa **Qiymət növü**, ƏDV statusu və hesablaşma parametrlərini yoxlayın.
4. Kartı yadda saxlayın. **Satış → Sifarişlər** və ya **Satışlar** formasında müştərinin seçildiyini yoxlayın.

   > **Şəkil əlavə ediləcək —** `media/user-guide/partners/customers/images/screen-01.png`: Müştəri siyahısı və müştəri roluna aid kart sahələri.

## Lüğət

| Termin | Bu səhifədəki mənası |
| --- | --- |
| Müştəri | Şirkətdən məhsul və ya xidmət alan tərəf-müqabildir. |
| Qiymət növü | Müştəri üçün tətbiq olunan satış qiyməti qaydasıdır. |
| ƏDV statusu | Müştərinin vergi rekvizitlərinin satış sənədində nəzərə alınmasına kömək edən məlumatdır. |

## FAQ

### Müştəri qiymət növünü dəyişsəm, köhnə sənədlər yenidən hesablanır?

Mövcud satış sənədlərində saxlanmış qiymətləri ayrıca yoxlayın. Tərəfdaş kartının sonrakı dəyişiklikləri köhnə sənədləri yenilədiyini fərz etməyin.

### Müştəri kartı satış yaradır?

Xeyr. Kart alıcı məlumatıdır; satış sənədini müvafiq Satış səhifəsində ayrıca yaradın.
