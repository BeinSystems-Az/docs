# Təchizatçı kartından istifadə etmək

**Təchizat → Təchizatçılar** siyahısı alış sənədlərində istifadə ediləcək təchizatçı tərəf-müqabilləri göstərir. Eyni tərəf müştəri rolunu da daşıyırsa, bunu tərəf-müqabil kartında ayrıca aktiv edin.

## İstifadə qaydası

1. **Təchizat → Təchizatçılar** səhifəsini açıb təchizatçının mövcud kartını axtarın.
2. Kart yoxdursa **Yeni** seçin, hüquqi adı, əlaqə məlumatını və vergi rekvizitlərini daxil edin.
3. **Təchizatçı** rolunu seçin, bank hesabı məlumatını sənədlə yoxlayıb əlavə edin.
4. Kartı yadda saxlayın və **Təchizat → Sifarişlər** və ya **Alışlar** formasında təchizatçı kimi tapıldığını yoxlayın.

   > **Şəkil əlavə ediləcək —** `media/user-guide/partners/suppliers/images/screen-01.png`: Təchizatçı filtrli siyahı və tərəfdaş kartında təchizatçı rolu.

## Lüğət

| Termin | Bu səhifədəki mənası |
| --- | --- |
| Təchizatçı | Şirkətə mal və ya xidmət təqdim edən tərəf-müqabildir. |
| VÖEN | Təchizatçının vergi identifikasiya nömrəsidir. |
| Bank hesabı | Təchizatçıya ödəniş üçün istifadə edilən hesab rekvizitidir. |

## FAQ

### Təchizatçı siyahısında tərəfdaş görünmür?

Kartın **Təchizatçı** rolunun aktiv olduğunu və kartın istifadəçi/filial əhatəsində olduğunu yoxlayın.

### Eyni tərəfdaşdan həm alıram, həm ona satıram. İki kart lazımdır?

Xeyr. Eyni tərəfdaş kartında **Təchizatçı** və **Müştəri** rollarını birlikdə istifadə edin.
