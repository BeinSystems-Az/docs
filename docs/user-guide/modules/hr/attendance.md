# Davamiyyət qeydi aparmaq

Davamiyyət səhifəsi əməkdaşın seçilmiş tarixdə işdə, yoxluqda və ya icazədə olmasını qeydə alır. Buradakı status maaş ödənişi deyil, işə davamiyyət məlumatıdır.

## İstifadə qaydası

1. **HR → Davamiyyət** səhifəsini açın və **Ay** filtrində işlədiyiniz ayı seçin.
2. Yeni qeyd yaradın, **Əməkdaş** və **Tarix** sahələrini doldurun.
3. **Status** sahəsində **İşdə**, **Yoxdur** və ya **İzinli** seçin. Lazım olduqda **Qeyd** əlavə edin.
4. Qeydi yadda saxlayın və siyahıda əməkdaş, tarix və statusun düzgün olduğunu yoxlayın.
5. Fayl çıxarmaq lazımdırsa **CSV** düyməsini seçib endirilən məlumatın ayını yoxlayın.

   > **Şəkil əlavə ediləcək —** `media/user-guide/hr/attendance/images/screen-01.png`: Ay filtri və əməkdaş/tarix/status sütunları.

## Lüğət

| Termin | Bu səhifədəki mənası |
| --- | --- |
| İşdə | Əməkdaş seçilmiş gündə işə gəldiyini bildirən statusdur. |
| Yoxdur | Əməkdaşın seçilmiş gündə işdə olmadığını göstərən statusdur. |
| İzinli | Əməkdaşın təsdiqlənmiş icazə və ya məzuniyyətdə olduğunu göstərən statusdur. |

## FAQ

### CSV hansı dövrü ixrac edir?

Səhifədə seçilmiş **Ay** üzrə məlumatı ixrac edir. Endirilən faylın ayını yoxlayın.

### Davamiyyət qeydi maaşı avtomatik hesablayır?

Maaş hesablaması ayrıca **Maaşlar və ödənişlər** səhifəsində hazırlanır. Hesablamadan əvvəl əməkdaşın davamiyyətini yoxlayın.
