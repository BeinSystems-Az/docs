# Şöbə yaratmaq

Şöbə əməkdaşları təşkilat daxilində struktur vahidlərinə ayırır. Əməkdaş kartında istifadə etməzdən əvvəl uyğun şöbənin sistemdə olmasını yoxlayın.

## İstifadə qaydası

1. **HR → Şöbələr** səhifəsini açıb **Yeni** seçin.
2. Formada şöbə üçün tələb olunan adı və göstərilən əlavə məlumatları daxil edin.
3. Şöbəni yadda saxlayın, siyahıda tapıb aktivlik və adını yoxlayın.
4. **HR → Əməkdaşlar** kartında əməkdaşa bu şöbəni bağlayın.

   > **Şəkil əlavə ediləcək —** `media/user-guide/hr/departments/images/screen-01.png`: Şöbə siyahısı və yeni şöbə forması.

## Lüğət

| Termin | Bu səhifədəki mənası |
| --- | --- |
| Şöbə | Əməkdaşları təşkilat daxilində qruplaşdıran vahiddir. |
| Əməkdaş | Şöbə ilə əlaqələndirilə bilən HR şəxs qeydidir. |

## FAQ

### Şöbə yaratdıqdan sonra əməkdaş kartı avtomatik dəyişir?

Xeyr. Şöbəni yaradandan sonra əməkdaş kartında ayrıca seçin.

### İstifadə olunan şöbəni silə bilərəm?

Əlaqəli əməkdaşlar varsa, silmə məhdudlaşdırıla bilər. Əvvəl şöbə əlaqələrini yoxlayın.
