# Maaş hesablayıb ödənişi qeyd etmək

Maaşlar və ödənişlər səhifəsi aylıq maaş hesabını hazırlayır, yoxlama və təsdiqdən sonra faktiki ödəniş qeydi saxlayır. Təsdiq ödənişi bankdan göndərmir.

## İstifadə qaydası

1. **HR → Maaşlar və ödənişlər** səhifəsini açıb hesablanacaq **Ay**ı seçin.
2. “Əməkdaşlar özəl, qeyri-neft sektorunda əsas iş yerində çalışır və əlavə vergi güzəştləri yoxdur” seçimində tətbiq olunan əmək şərtini təsdiqləyin.
3. **Ay üzrə maaşları hazırla** düyməsini seçin.
4. Siyahıda əməkdaşın bruto, vergi, sığorta tutulmaları, xalis məbləğ və işəgötürən xərcini yoxlayın. Əməkdaş sətrini açıb **Hesablama** tabında detallara baxın.
5. Məbləğ düzəlişi tələb olunursa **Brutonu düzəlt** əməliyyatını seçin, məbləğ və səbəbi daxil edin.
6. Hesablamanı yoxlayıb **Təsdiqlə** seçin. Sonra **Ödənişi qeyd et** əməliyyatı ilə faktiki ödəniş məlumatını daxil edin.
7. **Ödənişlər** tabında qeydə alınmış məbləğ və ödənilməmiş qalığı yoxlayın.

   > **Şəkil əlavə ediləcək —** `media/user-guide/hr/payroll/images/screen-01.png`: Ay seçimi, hesablamanın təsdiqi və ödəniş qeydi.

   > **Video əlavə ediləcək —** `media/user-guide/hr/payroll/videos/walkthrough-01.mp4`: Maaş hazırlamaq, hesablamanı yoxlamaq/təsdiqləmək və ödəniş qeydə almaq.

## Lüğət

## FAQ

### Maaş hesablamasını yaratmaq əməkdaşa pul göndərir?

Xeyr. Əvvəl hesablamanı təsdiqləyin; faktiki ödəniş baş verdikdən sonra **Ödənişi qeyd et** seçin.

### Hesablanmış bruto məbləği dəyişə bilərəm?

Müvafiq icazə ilə **Brutonu düzəlt** əməliyyatını seçib düzəliş səbəbini daxil edə bilərsiniz.
