# Əməkdaş kartı yaratmaq

Əməkdaş kartı şəxsi məlumatı şirkətdəki şöbə, vəzifə və iş şərtləri ilə əlaqələndirir. Kart maaş hesabı və davamiyyət kimi HR qeydlərində istifadə olunur.

## İstifadə qaydası

1. **HR → Əməkdaşlar** səhifəsini açıb **Yeni** seçin.
2. Şəxs əvvəl sistemdə yaradılıbsa **Mövcud şəxs** sahəsindən onu seçin. Yeni şəxsdirsə ad, soyad və əlaqə məlumatlarını formaya daxil edin.
3. İşçinin **Şöbə**, **Vəzifə** və **Filial** məlumatlarını seçin. Lazım olduqda **Seçim PIN-i** daxil edin.
4. **İş qrafiki** tabında iş günləri və saatlarını, **Maaş** tabında tarif və bruto məlumatını təşkilatın əmək şərtlərinə uyğun doldurun.
5. Kartı yadda saxlayın və əməkdaş siyahısında şəxsin, vəzifənin və filialın düzgünlüyünü yoxlayın.

   > **Şəkil əlavə ediləcək —** `media/user-guide/hr/employees/images/screen-01.png`: Şəxsi məlumat, şöbə/vəzifə/filial, qrafik və maaş tabları.

## Lüğət

| Termin | Bu səhifədəki mənası |
| --- | --- |
| Mövcud şəxs | Şəxsi məlumatı əvvəlcədən yaradılmış şəxslər siyahısından seçilən qeyd. |
| İş qrafiki | Əməkdaşın iş günlərini və saatlarını göstərən plan. |
| Bruto maaş | Vergi və tutulmalardan əvvəl müəyyən edilən əməkhaqqıdır. |
| Seçim PIN-i | Əməkdaşı sürətli seçmək üçün istifadə olunan dörd rəqəmli koddur. |

## FAQ

### Mövcud şəxs seçəndə ad və soyadı yenidən daxil etməliyəm?

Mövcud şəxs kartı seçiləndə şəxsi məlumat həmin qeyddən götürülür. Əlaqənin düzgün olduğunu yoxlayın.

### Əməkdaş kartını yaratmaq maaş ödənişi edir?

Xeyr. Kart iş məlumatlarını saxlayır; maaş hesabı və ödənişlər **Maaşlar və ödənişlər** səhifəsində aparılır.
