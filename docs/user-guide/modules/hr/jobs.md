# Vəzifə yaratmaq

Vəzifə əməkdaş kartında seçilən iş rolunun adını saxlayır. Vəzifə siyahısını şirkətdə istifadə olunan iş rol və adlarına uyğun saxlayın.

## İstifadə qaydası

1. **HR → Vəzifələr** səhifəsini açıb **Yeni** seçin.
2. Məcburi **Vəzifə** sahəsinə vəzifənin adını daxil edin. Lazım olduqda **Kod** yazın.
3. Yadda saxlayıb vəzifənin siyahıda göründüyünü yoxlayın.
4. **HR → Əməkdaşlar** səhifəsində əməkdaş kartının **Vəzifə** sahəsindən yeni vəzifəni seçin.

   > **Şəkil əlavə ediləcək —** `media/user-guide/hr/jobs/images/screen-01.png`: Vəzifə sahəsi tələb olunan yeni vəzifə forması.

## Lüğət

| Termin | Bu səhifədəki mənası |
| --- | --- |
| Vəzifə | Əməkdaşın şirkətdə tutduğu iş rolunun adıdır. |
| Kod | Vəzifəni daxili siyahıda tanımaq üçün əlavə edilən qısa identifikatordur. |

## FAQ

### Vəzifə adı olmadan qeyd yarada bilərəm?

Xeyr. **Vəzifə** sahəsi məcburidir.

### Vəzifə yaratmaq işçi təyin edir?

Xeyr. Vəzifə kartı yalnız siyahını hazırlayır; əməkdaşla əlaqəni əməkdaş kartında qurun.
