# Əsas vəsait kartı yaratmaq

Əsas vəsait kartı uzunmüddətli aktivin ilkin dəyərini, istifadə yerini, məsul əməkdaşı və amortizasiya məlumatlarını saxlayır. Kart transfer, satış və silinmə sənədlərini əvəz etmir.

## İstifadə qaydası

1. **Mühasibatlıq → Əsas vəsaitlər → Əsas vəsait kartları** səhifəsini açıb **Yeni** seçin.
2. Məcburi **Ad** sahəsini doldurun. Aktiv alışdan yaranıbsa təsdiqlənmiş **Alış sənədi**ni və ya **Anbar mədaxili**ni mənbə kimi seçin.
3. **İlkin dəyər**, **Kateqoriya**, yerləşdiyi **Anbar**, istifadə yeri və **Cavabdeh əməkdaş**ı daxil edin.
4. İstifadə müddəti və amortizasiya qaydasını şirkətin uçot siyasətinə uyğun doldurun.
5. Kartı yadda saxlayıb siyahıda aktivin statusunu və dəyərini yoxlayın.

   > **Şəkil əlavə ediləcək —** `media/user-guide/accounting/fixed-assets/images/screen-01.png`: Mənbə alış sənədi, ilkin dəyər, cavabdeh və amortizasiya sahələri.

## Lüğət

| Termin | Bu səhifədəki mənası |
| --- | --- |
| Əsas vəsait | Uzun müddət istifadə olunan maddi aktivdir. |
| İlkin dəyər | Aktivin uçota alınan başlanğıc qiymətidir. |
| Cavabdeh əməkdaş | Aktivə görə məsuliyyət daşıyan əməkdaşdır. |
| Amortizasiya | Aktiv dəyərinin istifadə müddətinə bölünmüş uçotudur. |

## FAQ

### Əsas vəsait kartı alma sənədi təsdiqlənəndə avtomatik yaranır?

Bu, alış sənədindəki əsas vəsait mənbəyindən asılıdır. Kart yaranmayıbsa, təsdiqlənmiş alış mənbəyi ilə ayrıca yaradın.

### Kartı yaratmaq amortizasiya başlayır?

Kart aktiv məlumatını saxlayır; amortizasiya icrası **İllik amortizasiya** səhifəsində ayrıca aparılır.
