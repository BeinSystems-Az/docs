# Əsas vəsaiti transfer etmək

Əsas vəsait transferi aktivin filialını, istifadə yerini və ya cavabdeh əməkdaşını dəyişmək üçün sənədləşdirilən hərəkətdir.

## İstifadə qaydası

1. **Mühasibatlıq → Əsas vəsaitlər → Transferlər** səhifəsini açıb **Yeni** seçin.
2. Transfer olunacaq **Əsas vəsait**i və cari/ yeni yerləşmə və məsul şəxs sahələrini formadakı kimi doldurun.
3. Transfer tarixini və qeydi yoxlayın.
4. Sənədi yadda saxlayıb təsdiq edin. Əsas vəsait kartında yeni filialı, yeri və məsul əməkdaşı yoxlayın.

   > **Şəkil əlavə ediləcək —** `media/user-guide/accounting/asset-transfers/images/screen-01.png`: Aktiv, əvvəlki və yeni istifadə yeri/məsul şəxsi.

## Lüğət

| Termin | Bu səhifədəki mənası |
| --- | --- |
| Transfer | Əsas vəsaitin məsul və ya yerləşmə məlumatını dəyişən uçot sənədidir. |
| Cari dəyər | Transferdən əvvəl aktiv kartında olan məsul/yer məlumatıdır. |

## FAQ

### Transfer aktivin balans dəyərini dəyişir?

Transfer yeri və məsuliyyət məlumatını dəyişir. Dəyər təsiri olub-olmadığını sənəddəki hesab yazılışı və jurnal ilə yoxlayın.

### Transfer tarixçəsini harada görürəm?

Əsas vəsait kartının **Hərəkətlər** hesabatını açın.
