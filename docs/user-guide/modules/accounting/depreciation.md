# İllik amortizasiya hesablamaq

İllik amortizasiya səhifəsi əsas vəsaitlər üzrə seçilmiş dövrün amortizasiya icrasını hazırlayıb nəticəsini göstərir.

## İstifadə qaydası

1. **Mühasibatlıq → Əsas vəsaitlər → İllik amortizasiya** səhifəsini açın.
2. Hesablanacaq dövrü seçin və icradan əvvəl aktivlərin amortizasiya qaydasını yoxlayın.
3. Yeni hesablama icrasını başladın.
4. Yaranmış nəticə sətirlərini və aktivlərin qalıq dəyərini yoxlayın; nəticəni baş kitab hesabatında tutuşdurun.

   > **Şəkil əlavə ediləcək —** `media/user-guide/accounting/depreciation/images/screen-01.png`: Dövr seçimi və amortizasiya nəticə siyahısı.

## Lüğət

| Termin | Bu səhifədəki mənası |
| --- | --- |
| Amortizasiya icrası | Seçilmiş dövr üzrə aktivlər üçün yaradılmış hesablamadır. |
| Yığılmış amortizasiya | Aktivin əvvəlki dövrlərdə xərcə silinmiş ümumi dəyərdir. |
| Balans dəyəri | İlkin dəyərdən yığılmış amortizasiya çıxıldıqdan sonra qalan məbləğdir. |

## FAQ

### Eyni dövr üçün ikinci dəfə icra başlada bilərəm?

İcra təkrarı sistem tərəfindən məhdudlaşdırıla bilər. Mövcud icra qeydlərini yoxlamadan eyni dövrü yenidən yaratmayın.

### Amortizasiya aktivin ilkin dəyərini dəyişir?

Xeyr. Amortizasiya yığılmış dəyər və balans dəyərinə təsir edir; ilkin dəyər saxlanılır.
