# Əsas vəsaiti satmaq

Əsas vəsait satışı aktivin şirkətdən çıxmasını və satış uçotunu ayrıca sənədlə rəsmiləşdirir. Aktiv kartının məbləğini əl ilə dəyişmək satış sənədini əvəz etmir.

## İstifadə qaydası

1. **Mühasibatlıq → Əsas vəsaitlər → Satışlar** səhifəsini açıb **Yeni** seçin.
2. Satılan əsas vəsaiti, satış tarixini, alıcı və sənədin tələb etdiyi satış məbləğini daxil edin.
3. Aktivin cari balans dəyərini və tələb olunan digər sahələri yoxlayın.
4. Sənədi yadda saxlayıb təsdiq edin. Aktiv kartının statusunu və mühasibat jurnalı yazılışını yoxlayın.

   > **Şəkil əlavə ediləcək —** `media/user-guide/accounting/asset-sales/images/screen-01.png`: Satış forması və seçilmiş əsas vəsaitin balans məlumatı.

## Lüğət

| Termin | Bu səhifədəki mənası |
| --- | --- |
| Əsas vəsait satışı | Aktivin mülkiyyətindən çıxması üzrə uçot sənədidir. |
| Satış məbləği | Aktivin alıcıya verilməsi üçün sənəddə qeydə alınan dəyərdir. |

## FAQ

### Satışdan əvvəl aktiv kartını deaktiv etmək lazımdır?

Əvvəl satış sənədini yaradıb təsdiq edin; statusun necə dəyişdiyini aktiv kartında yoxlayın.

### Satış sənədi jurnal yazılışı yaradır?

Mühasibat modulu və hesab sxemindən asılı olaraq yazılışı **Əməliyyat jurnalı** səhifəsində yoxlayın.
