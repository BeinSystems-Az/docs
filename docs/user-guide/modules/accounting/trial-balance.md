# Dövriyyə-saldo cədvəlinə baxmaq

Dövriyyə-saldo cədvəli hesablar üzrə dövrün əvvəlindəki və sonundakı qalıqları, həmçinin debit/kredit dövriyyəsini göstərir.

## İstifadə qaydası

1. **Mühasibatlıq → Hesabatlar → Dövriyyə-saldo cədvəli** səhifəsini açın.
2. Başlanğıc və son tarixi seçin, tələb olunan hesab və təsdiq statusu filtrlərini yoxlayın.
3. Nəticəni yeniləyib açılış qalığı, debit/kredit dövriyyəsi və son qalığı müqayisə edin.
4. Hesab sətrini seçərək **Hesab tarixçəsi** panelini açın; yazılış sətrindən mənbə sənədinə keçin.

   > **Şəkil əlavə ediləcək —** `media/user-guide/accounting/trial-balance/images/screen-01.png`: Hesabat dövrü və hesab tarixçəsi paneli.

## Lüğət

| Termin | Bu səhifədəki mənası |
| --- | --- |
| Açılış qalığı | Seçilmiş dövrün əvvəlində hesaba aid qalıqdır. |
| Dövriyyə | Dövr ərzində hesabda yaranmış debet və kredit yazılışlarının cəmidir. |
| Son qalıq | Dövrün sonunda hesabda göstərilən uçot qalığıdır. |

## FAQ

### Qaralama sənədlər hesabatda görünür?

**Yalnız təsdiqlənmişlər** filtri aktivdirsə, qaralamalar daxil edilmir. Filtrin dəyərini yoxlayın.

### Hesab sətrindən mənbə sənədə keçmək olur?

Hesab tarixçəsini açın və yazılış sətrini seçin; source link mövcuddursa sənəd oradan açılır.
