# Əsas vəsaiti silmək

Əsas vəsait silinməsi istifadədən çıxan aktivi uçotdan çıxarmağı rəsmiləşdirir. Sənəd satılmayan və artıq istifadə olunmayan aktivlər üçün istifadə edilir.

## İstifadə qaydası

1. **Mühasibatlıq → Əsas vəsaitlər → Silinmələr** səhifəsini açıb **Yeni** seçin.
2. Silinəcək aktiv, əməliyyat tarixi və formanın tələb etdiyi silinmə səbəbi/qeyd sahələrini doldurun.
3. Aktivin cari status və balans məlumatını yoxlayın.
4. Sənədi yadda saxlayıb təsdiq edin. Əsas vəsait kartında vəziyyətin dəyişməsini və **Əməliyyat jurnalı** yazılışını yoxlayın.

   > **Şəkil əlavə ediləcək —** `media/user-guide/accounting/asset-scraps/images/screen-01.png`: Əsas vəsait seçimi, silinmə tarixi və səbəb qeydi.

## Lüğət

| Termin | Bu səhifədəki mənası |
| --- | --- |
| Silinmə | Aktivin istifadədən çıxıb uçot vəziyyətinin dəyişməsi sənədidir. |
| Silinmə səbəbi | Aktivin niyə uçotdan çıxarıldığını izah edir. |

## FAQ

### Aktiv satılırsa silinmə sənədindən istifadə etməliyəm?

Xeyr. Satış varsa **Əsas vəsaitlər → Satışlar** sənədindən istifadə edin.

### Sənəd təsdiqlənəndən sonra aktiv kartı qalır?

Kartın tarixçəsi saxlanır, amma aktivin statusu dəyişə bilər. Təsdiqdən sonra kart və jurnal məlumatlarını yoxlayın.
