# Mənfəət və ya zərər hesabatına baxmaq

Mənfəət və ya Zərər hesabatı seçilmiş dövr ərzində uçota alınan gəlir və xərcləri ümumiləşdirir.

## İstifadə qaydası

1. **Mühasibatlıq → Hesabatlar → Mənfəət və ya Zərər** səhifəsini açın.
2. Başlanğıc və son tarixi seçib hesabatı yeniləyin.
3. Gəlir və xərc qruplarını, yekun nəticəni yoxlayın.
4. Gözlənilməz məbləği uyğun hesab və **Əməliyyat jurnalı** yazılışları üzrə araşdırın.

   > **Şəkil əlavə ediləcək —** `media/user-guide/accounting/profit-loss/images/screen-01.png`: Dövr üzrə gəlir/xərc bölmələri və yekun nəticə.

## Lüğət

| Termin | Bu səhifədəki mənası |
| --- | --- |
| Gəlir | Dövr ərzində şirkətin fəaliyyətindən yaranan uçot məbləğidir. |
| Xərc | Dövr ərzində fəaliyyət üçün qeydə alınan məsrəfdir. |
| Hesabat dövrü | Hesabata daxil edilən başlanğıc və son tarix aralığıdır. |

## FAQ

### Bu hesabat balansdan nə ilə fərqlənir?

Bu hesabat dövr üzrə gəlir və xərci, balans isə müəyyən tarixə aktiv/öhdəlik/kapital qalıqlarını göstərir.

### Qaralama xərclər hesabatda görünür?

Hesabata yalnız uçota yazılmış əməliyyatlar daxil olur. Xərc sənədinin statusu və hesabat filtrlərini yoxlayın.
