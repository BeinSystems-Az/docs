# Mühasibat hesabı yaratmaq

Hesablar səhifəsində mühasibat uçotu üçün hesab planı yaradılır. Hesab kodu, növü və ana hesabı şirkətin təsdiqlənmiş hesab planına uyğun olmalıdır.

## İstifadə qaydası

1. **Mühasibatlıq → Konfiqurasiya → Hesablar** səhifəsini açıb mövcud hesabı kod və ya adla axtarın.
2. Yeni hesab lazımdırsa **Yeni** seçin, məcburi **Kod** və **Ad** sahələrini doldurun.
3. **Kateqoriya** və **Tip** seçin. Alt hesabdırsa uyğun **Ana hesab**ı göstərin.
4. Hesabı yadda saxlayıb siyahıda kod, ad və aktivlik vəziyyətini yoxlayın.

   > **Şəkil əlavə ediləcək —** `media/user-guide/accounting/accounts/images/screen-01.png`: Hesab forması, ana hesab və kateqoriya/növ seçimləri.

## Lüğət

| Termin | Bu səhifədəki mənası |
| --- | --- |
| Hesab planı | Maliyyə əməliyyatlarının mühasibat hesablarına qruplaşdırılmasıdır. |
| Ana hesab | Alt hesabları qruplaşdıran yuxarı səviyyəli hesabdır. |
| Hesab tipi | Hesabın uçot planındakı funksional təsnifatıdır. |

## FAQ

### Hesab kodu olmadan hesab yarada bilərəm?

Xeyr. **Kod** və **Ad** məcburi sahələrdir.

### İstifadə olunan hesabı silə bilərəm?

Əvvəlki yazılışlarla əlaqəli hesabın silinməsi məhdudlaşdırıla bilər. Yeni əməliyyatlardan çıxarmaq lazımdırsa aktivlik parametrini yoxlayın.
