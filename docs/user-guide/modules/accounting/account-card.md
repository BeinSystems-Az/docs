# Hesab kartına baxmaq

Hesab kartı seçilmiş mühasibat hesabının dövr ərzi hərəkətlərini və mənbə yazılışlarını göstərir.

## İstifadə qaydası

1. **Mühasibatlıq → Hesabatlar → Hesab kartı** səhifəsini açın.
2. Hesabı, tarix aralığını və lazım olan tərəfdaş/filtrləri seçin.
3. Hesabatı yeniləyib debit/kredit sətirlərini, tarix və qalıqları yoxlayın.
4. Yazılışın ilkin səbəbini görmək üçün sətri açıb mənbə sənədinə keçin.

   > **Şəkil əlavə ediləcək —** `media/user-guide/accounting/account-card/images/screen-01.png`: Hesab seçimi, dövr və yazılış siyahısı.

## Lüğət

| Termin | Bu səhifədəki mənası |
| --- | --- |
| Hesab kartı | Bir mühasibat hesabı üzrə əməliyyat tarixçəsidir. |
| Yazılış sətri | Hesaba aid debet və ya kredit məbləğidir. |
| Mənbə sənəd | Hesab kartında göstərilən yazılışın yarandığı biznes sənədidir. |

## FAQ

### Hesab kartı ilə dövriyyə-saldo cədvəli eynidir?

Xeyr. Hesab kartı konkret hesabın sətir-sətir tarixçəsini, dövriyyə-saldo isə hesabların xülasəsini göstərir.

### Yazılış məbləği yanlışdırsa nə etməliyəm?

Jurnalda mənbə sənədini tapıb onun statusunu, ödənişini və müxabirləşmə sazlamasını yoxlayın.
