# Əməliyyat jurnalında yazılışı yoxlamaq

Əməliyyat jurnalı təsdiqlənmiş biznes sənədlərindən yaranan mühasibat yazılışlarını göstərir. Jurnal qeydi ilkin sənədlə birlikdə yoxlanmalıdır; əməliyyatı jurnal sətrindən dəyişməyin.

## İstifadə qaydası

1. **Mühasibatlıq → Əməliyyat jurnalı** səhifəsini açın.
2. Tarix, status, hesab və tərəf-müqabil filtrləri ilə axtardığınız yazılışı tapın.
3. Sətri açıb debit/kredit hesablarını, məbləği və mənbə sənədini yoxlayın.
4. Yazılış səhvdirsə, onu yaradan alış, satış, ödəniş və ya xərc sənədini açıb qaydanı yoxlayın.

   > **Şəkil əlavə ediləcək —** `media/user-guide/accounting/entries/images/screen-01.png`: Jurnal filtrləri və mənbə sənəd bağlantısı olan seçilmiş yazılış.

## Lüğət

| Termin | Bu səhifədəki mənası |
| --- | --- |
| Əməliyyat jurnalı | Mühasibat yazılışlarını tarix və mənbə üzrə izləyən siyahıdır. |
| Debet | Yazılışın hesab planına uyğun debet tərəfidir. |
| Kredit | Yazılışın hesab planına uyğun kredit tərəfidir. |
| Mənbə sənəd | Mühasibat yazılışını yaradan təsdiqlənmiş biznes sənədidir. |

## FAQ

### Yazılış niyə jurnalda görünmür?

Tarix və status filtrlərini yoxlayın. Bəzi yazılışlar mənbə sənədi təsdiqləndikdən sonra yaranır.

### Jurnal sətrini redaktə edib hesabı düzəldə bilərəm?

Əməliyyatı yaradan mənbə sənədini və müxabirləşmə sazlamasını yoxlayın; jurnal qeydi mənbədən yoxlanmalıdır.
