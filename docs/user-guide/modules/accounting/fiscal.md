# Maliyyə dövrü ayarlarını dəyişmək

Maliyyə dövrü ayarları əsas valyutanı, ölkəni, maliyyə ilinin başlanğıcını və Mənfəət/Zərər hesabatında gəlir-xərci tanıma metodunu təyin edir. Tanıma metodu hesabatın hesablanmasına təsir edir.

## İstifadə qaydası

### Maliyyə ilini və uçot metodunu seçin

1. **Ayarlar → Mühasibatlıq → Maliyyə dövrü** səhifəsini açın.
2. **Əsas Valyuta** və **Ölkə** seçimlərini şirkətin istifadə etdiyi məlumatla tutuşdurun.
3. **Maliyyə ilinin başlanğıc tarixi** sahəsində uçot ilinin başladığı günü seçin.
4. **Mənfəət/Zərər üçün tanınma metodu** sahəsində şirkətin uçot siyasətinə uyğun **Hesablama metodu** və ya **Kassa metodu** seçin.

   > **Şəkil əlavə ediləcək —** `media/user-guide/accounting/fiscal/images/screen-01.png`: Əsas valyuta, ölkə, maliyyə ilinin başlanğıcı və gəlir-xərc tanıma metodu.

### Dəyişikliyi yoxlayın

5. Səlahiyyətiniz varsa dəyişiklikləri yadda saxlayın və səhifəni yenidən açıb saxlanmış dəyərləri yoxlayın.
6. Mənfəət və ya Zərər hesabatını yeniləyib seçilmiş metodla nəticənin dəyişdiyini yoxlayın.
7. Metod dəyişikliyinin artıq təsdiqlənmiş əməliyyat jurnallarını dəyişdirmədiyini nəzərə alın; uçot siyasətinə təsir edən dəyişikliyi məsul mühasiblə razılaşdırın.

## Lüğət

| Termin | Bu səhifədəki mənası |
| --- | --- |
| Əsas valyuta | Şirkətin maliyyə hesabatlarında əsas götürdüyü valyutadır. |
| Maliyyə ili | Şirkətin hesabat dövrü kimi istifadə etdiyi illik uçot aralığıdır. |
| Hesablama metodu | Gəlir və xərci yaranma hadisəsinə əsasən tanıma qaydasıdır. |
| Kassa metodu | Gəlir və xərci pulun faktiki daxil olması və ya ödənməsi ilə əlaqələndirən qaydadır. |

## FAQ

### Tanıma metodunu dəyişəndə təsdiqlənmiş yazılışlar dəyişir?

Bu parametr Mənfəət/Zərər hesabatının hesablanma metoduna təsir edir; təsdiqlənmiş əməliyyat yazılışlarının dəyişdiyini nəzərdə tutmur.

### Maliyyə ilinin başlanğıcını istənilən tarixə qoya bilərəm?

Sahə tarix seçməyə imkan verir, amma tarix şirkətin uçot və hesabat dövrünə uyğun olmalıdır. Dəyişiklikdən əvvəl məsul mühasiblə razılaşdırın.

### Əsas valyutanı dəyişmək əvvəlki məbləğləri yenidən hesablayır?

Belə nəticəni avtomatik qəbul etməyin. Dəyişiklikdən sonra hesabatları və valyuta məzənnəsi tarixçəsini ayrıca yoxlayın.
