# Vergi profilini tənzimləmək

Vergi profili şirkətin vergi ödəyicisi növünü və əsas vergi rejimini saxlayır. Profilin hazırlıq yoxlaması tamamlanmamış və ya çatışmayan məlumatları göstərə bilər.

## İstifadə qaydası

### Profil məlumatlarını daxil edin

1. **Ayarlar → Mühasibatlıq → Vergi profili** səhifəsini açın.
2. **Vergi ödəyicisinin növü** sahəsində şirkətin qeydiyyat formasına uyğun seçimi göstərin.
3. **Əsas vergi rejimi** sahəsində tətbiq olunan rejimi seçin. Şirkət ƏDV ödəyicisidirsə ƏDV vəziyyətini uyğunlaşdırın.
4. Üfüqi monitorinq parametri şirkətinizə tətbiq edilirsə, onu mühasiblə dəqiqləşdirib seçin. Məlumatı bilmirsinizsə təsadüfi seçim etməyin.

   > **Şəkil əlavə ediləcək —** `media/user-guide/accounting/tax-profile/images/screen-01.png`: Vergi ödəyicisi növü, əsas vergi rejimi, ƏDV və üfüqi monitorinq parametrləri.

### Yadda saxlayın və hazırlığı yoxlayın

5. Dəyişiklik icazəniz varsa **Yadda saxla** seçin.
6. Səhifənin hazırlıq nəticəsini oxuyun. Xəbərdarlıq qalan sahəni tamamlayın və yenidən yoxlayın.
7. Tətbiq olunan rejimin alış və satış sənədlərində vergi hesablanmasına uyğun olduğunu məsul mühasiblə yoxlayın.

## Lüğət

| Termin | Bu səhifədəki mənası |
| --- | --- |
| Vergi profili | Şirkətin vergi ödəyicisi statusu və əsas vergi rejimi parametrləridir. |
| Əsas vergi rejimi | Şirkətin əsas vergi qaydasını göstərən seçimdir. |
| ƏDV ödəyicisi | Əlavə dəyər vergisi üzrə qeydiyyat statusunu bildirir. |
| Hazırlıq yoxlaması | Profil məlumatlarının tətbiq üçün yetərli olub-olmadığını göstərən nəticədir. |

## FAQ

### Vergi profilindəki seçimləri özüm təyin edə bilərəm?

Yalnız şirkətin vergi qeydiyyatına uyğun məlumatı dəqiq bildiyiniz halda dəyişin. Şübhə olduqda mühasiblə təsdiqləyin.

### Hazırlıq xəbərdarlığı qalırsa nə etməliyəm?

Xəbərdarlıqda göstərilən sahəni və tələb olunan məlumatı tamamlayıb saxlayın. Sonra hazırlıq yoxlamasını yenidən başladın.

### Vergi profilini dəyişmək əvvəlki sənədləri yenidən hesablayır?

Əvvəlki sənədlərin avtomatik dəyişdiyini güman etməyin. Dəyişikliyin təsirini yeni sənəd və hesabatda yoxlayın.
