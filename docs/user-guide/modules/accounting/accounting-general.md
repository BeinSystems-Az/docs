# Müxabirləşmə sxemlərini yoxlamaq

Müxabirləşmə sxemləri biznes sənədləri təsdiqlənəndə istifadə olunan mühasibat hesabı əlaqələrini göstərir. Səhifədə hesab qruplarının sazlanma vəziyyətini və bəzi hallarda tranzit hesab seçimlərini yoxlayın.

## İstifadə qaydası

### Hesab qruplarının vəziyyətini yoxlayın

1. **Ayarlar → Mühasibatlıq → Müxabirləşmə sxemləri** səhifəsini açın.
2. Səhifədə göstərilən hesab qruplarını və hazırlıq bildirişlərini yoxlayın. Qrupun yanında hesab tələb olunduğu bildirilirsə, həmin hesab əlaqəsi tamamlanmayıb.
3. Tranzit hesab sahəsi görünürsə, onu yalnız həmin biznes axınında aralıq hesab kimi istifadə ediləcəyi halda seçin. Mövcud kassa və ya bank hesabı əlaqəsi olan vəziyyətdə tranzit hesab ehtiyat seçim kimi işləyə bilər.
4. Dəyişiklik icazəniz varsa, uyğun mühasibat hesabını seçib **Yadda saxla** əməliyyatını yerinə yetirin. Sonra səhifəni yenidən açaraq seçimlərin saxlandığını və hazırlıq bildirişinin dəyişdiyini yoxlayın.

   > **Şəkil əlavə ediləcək —** `media/user-guide/accounting/accounting-general/images/screen-01.png`: Hesab qrupları, tranzit hesab sahəsi və sazlama hazırlığı xəbərdarlığı.

### Nəticəni əməliyyat sənədində yoxlayın

5. Sazlamadan sonra uyğun biznes sənədini təsdiqləyin və yaranan yazılışı **Mühasibatlıq → Əməliyyat jurnalı** səhifəsində yoxlayın.
6. Jurnalda yazılış yoxdursa, sənəd növünün mühasibat inteqrasiyasını və hesab xəritəsini administratorla yoxlayın.

## Lüğət

| Termin | Bu səhifədəki mənası |
| --- | --- |
| Müxabirləşmə sxemi | Biznes əməliyyatının hansı mühasibat hesablarında göstəriləcəyini təyin edən hesab əlaqələridir. |
| Tranzit hesab | Əməliyyatın hesablar arasında keçid mərhələsini izləmək üçün istifadə oluna bilən aralıq hesabdır. |
| Hazırlıq bildirişi | Sənəd nəticələrinin düzgün yaranması üçün tələb olunan hesab əlaqələrinin tam olub-olmadığını göstərən xəbərdarlıqdır. |

## FAQ

### Hesab əlaqəsi boş qalarsa nə baş verir?

Həmin hesab əlaqəsindən asılı mühasibat yazılışı yarana bilməyə və ya hazırlıq xəbərdarlığı görünə bilər. Sənədi təsdiqləməzdən əvvəl tələb olunan hesabı seçin.

### Tranzit hesabı hər şirkətdə mütləq seçməliyəm?

Səhifə bunu tələb etmirsə, seçimi biznes axınınızın hesablaşma qaydasına uyğun edin. Mövcud kassa və bank hesabı əlaqələri tranzit hesab ehtiyacına təsir edə bilər.

### Burada edilən dəyişiklik əvvəlki yazılışları dəyişir?

Bu səhifə hesab sxeminin konfiqurasiyası üçündür. Əvvəlki yazılışın dəyişdiyini fərz etməyin; nəticəni müvafiq sənəd və əməliyyat jurnalında yoxlayın.
