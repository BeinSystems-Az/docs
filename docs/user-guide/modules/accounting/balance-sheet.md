# Balans hesabatına baxmaq

Balans hesabatı seçilmiş tarixə şirkətin aktiv, öhdəlik və kapital vəziyyətini göstərir.

## İstifadə qaydası

1. **Mühasibatlıq → Hesabatlar → Balans hesabatı** səhifəsini açın.
2. Hesabat tarixini və mövcud filtr seçimlərini daxil edib yeniləyin.
3. Aktiv və öhdəlik/kapital qruplarının cəmlərini tutuşdurun.
4. Fərqi hesab səviyyəsində araşdırmaq üçün hesabatdakı hesab detalını və **Əməliyyat jurnalı** yazılışlarını yoxlayın.

   > **Şəkil əlavə ediləcək —** `media/user-guide/accounting/balance-sheet/images/screen-01.png`: Balans hesabatında aktivlər, öhdəliklər və kapital cəmləri.

## Lüğət

| Termin | Bu səhifədəki mənası |
| --- | --- |
| Aktiv | Şirkətin sahib olduğu iqtisadi resursdur. |
| Öhdəlik | Şirkətin başqa tərəflərə borc və məsuliyyətidir. |
| Kapital | Aktivlərdən öhdəliklər çıxıldıqdan sonra qalan paydır. |

## FAQ

### Balans hesabatı hansı dövrü göstərir?

Hesabat seçilmiş tarixə vəziyyəti göstərir; tarix sahəsində konkret hesabat gününü seçin.

### Balans bərabər deyilsə nəyi yoxlamalıyam?

Hesab planı, təsdiqlənmiş yazılışlar və seçilmiş tarixə qədər olan sənədləri yoxlayın.
