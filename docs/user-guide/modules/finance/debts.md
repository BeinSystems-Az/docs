# Tərəfdaş borclarını yoxlamaq

Borclar səhifəsi müştəri və təchizatçılar üzrə açıq hesablaşmaları göstərir. Bu səhifə borcu araşdırmaq üçündür; özü yeni ödəniş yaratmır.

## İstifadə qaydası

1. **Maliyyə → Borclar** səhifəsini açın.
2. Tərəfdaş və səhifədə mövcud olan tarix, istiqamət və status filtrlərini seçin.
3. Debitor və kreditor məbləğlərini, açıq sənədləri və ödənişləri müqayisə edin.
4. Borcu bağlamaq üçün əlaqəli sənədi müəyyən edin, sonra **Ödənişlər** səhifəsində həmin tərəfdaş üçün uyğun daxilolma və ya məxaric ödənişi yaradın.

   > **Şəkil əlavə ediləcək —** `media/user-guide/finance/debts/images/screen-01.png`: Borc siyahısında tərəfdaş, açıq qalıq və mənbə hesablaşma.

## Lüğət

| Termin | Bu səhifədəki mənası |
| --- | --- |
| Debitor borcu | Müştərinin şirkətə ödəməli olduğu açıq məbləğdir. |
| Kreditor borcu | Şirkətin təchizatçıya ödəməli olduğu açıq məbləğdir. |
| Açıq qalıq | Ödənişlə tam bağlanmamış hesablaşma məbləğidir. |

## FAQ

### Borc hesabatından birbaşa ödəniş yarada bilərəm?

Ödənişi **Maliyyə → Ödənişlər** səhifəsində ayrıca yaradın və borcu yaradan tərəfdaş/sənədlə əlaqələndirin.

### Borc məbləği yenilənmirsə nəyi yoxlayım?

Əlaqəli faktura və ödənişlərin statusunu, tərəfdaş seçimini və filtrlərin eyni dövrü əhatə etdiyini yoxlayın.
