# Xərc qeyd etmək

Birbaşa xərc sənədi pul hesabından çıxan məbləği xərc maddəsi ilə əlaqələndirir. O, alış fakturasından fərqli olaraq ayrıca təchizatçı mal qəbulu yaratmır.

## İstifadə qaydası

1. **Maliyyə → Xərclər** səhifəsini açıb **Yeni** seçin.
2. **Hesab** sahəsində ödənişin aid olduğu pul hesabını seçin. Tarix, filial, layihə və açıqlamanı ehtiyac olduqda doldurun.
3. **Xərc sətirləri** hissəsində xərc maddəsi və məbləğ daxil edin. Maya dəyərinə aid etmək tələb olunursa, yalnız uyğun alış sənədi və bölüşdürmə seçimini göstərin.
4. Cəmi yoxlayıb sənədi yadda saxlayın, sonra **Təsdiq** edin.
5. Əməliyyat jurnalı və pul hesabı hərəkətində yazılışın yarandığını yoxlayın.

   > **Şəkil əlavə ediləcək —** `media/user-guide/finance/expenses/images/screen-01.png`: Xərc hesabı, xərc maddəsi və məbləğ sətri.

## FAQ

### Xərc sənədi təsdiqlənmədən pul hesabı dəyişir?

Xərcin pul və mühasibat təsiri sənədin təsdiqindən asılıdır. Qaralama statusunda yekun hesab hərəkəti gözləməyin.

### Birbaşa xərc alış fakturasını əvəz edir?

Xeyr. Mal alışı və təchizatçı borcu üçün alış axınında faktura/alış sənədi yaradın.
