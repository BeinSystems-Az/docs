# Hesablar arasında transfer etmək

Transfer şirkətin bir pul hesabındakı məbləği digər pul hesabına keçirir. Bu əməliyyat tərəfdaş ödənişi deyil və ümumi pul qalığını artırmır.

## İstifadə qaydası

1. **Maliyyə → Transferlər** səhifəsini açıb **Yeni** seçin.
2. **Hesabdan** mənbə, **Hesaba** təyinat pul hesabını seçin.
3. **Valyuta** və **Məbləğ** daxil edin, tarix və qeydi yoxlayın. Mənbə və təyinat hesabları eyni olmamalıdır.
4. Sənədi yadda saxlayın və **Təsdiq** edin.
5. Hər iki hesabın hərəkət tarixçəsində mənbə çıxışını və təyinat daxilolmasını tutuşdurun.

   > **Şəkil əlavə ediləcək —** `media/user-guide/finance/transfers/images/screen-01.png`: Mənbə/təyinat hesabı, valyuta və transfer məbləği.

## Lüğət

| Termin | Bu səhifədəki mənası |
| --- | --- |
| Mənbə hesab | Vəsaitin çıxacağı pul hesabıdır. |
| Təyinat hesab | Vəsaitin daxil olacağı pul hesabıdır. |
| Transfer | Vəsaitin şirkətin öz hesabları arasında hərəkətidir. |

## FAQ

### Transfer ümumi pul qalığını dəyişir?

Xeyr. Mənbə hesab azalır, təyinat hesab artır; valyutaları eyni hesablama qaydasında müqayisə edin.

### Hesablarım siyahıda görünmürsə nə etməliyəm?

Hesabların aktivliyini, valyuta uyğunluğunu və filial/istifadəçi icazələrini yoxlayın.
