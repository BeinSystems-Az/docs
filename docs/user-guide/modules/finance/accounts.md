# Maliyyə hesabı yaratmaq

Maliyyə hesabı nağd pulun və ya bank vəsaitinin ERP-də izlənəcəyi hesabdır. Hesab kartı açılış qalığını özü yaratmır.

## İstifadə qaydası

1. **Maliyyə → Hesablar** səhifəsini açıb **Yeni** seçin.
2. Hesabın **Ad**ını daxil edin, **Tip** sahəsində nağd və ya bank hesabını, **Valyuta** sahəsində hesablaşma valyutasını seçin.
3. Təşkilatın mühasibat uçotu istifadə olunursa, uyğun **Mühasibat hesabı** ilə əlaqələndirin.
4. Hesabı yadda saxlayın və siyahıda aktiv, düzgün valyutalı göründüyünü yoxlayın.

   > **Şəkil əlavə ediləcək —** `media/user-guide/finance/accounts/images/screen-01.png`: Hesab adı, tipi, valyutası və əlaqəli mühasibat hesabı.

## Lüğət

| Termin | Bu səhifədəki mənası |
| --- | --- |
| Nağd hesab | Kassadakı nağd vəsaitin uçot hesabıdır. |
| Bank hesabı | Bankda saxlanılan pul vəsaitinin ERP qeydidir. |
| Mühasibat hesabı | Maliyyə hərəkətinin baş kitabda yazılacağı hesabdır. |

## FAQ

### Hesab kartını yaratmaq balans yaradır?

Xeyr. Balansı açılış uçotu və təsdiqlənən ödəniş/transfer əməliyyatları müəyyən edir.

### Hesabın valyutasını sonradan dəyişə bilərəm?

Hərəkətləri olan hesabın valyutasına dəyişiklik təsir edə bilər. Hesabı əməliyyatlarda istifadə etməzdən əvvəl valyutanı dəqiqləşdirin.
