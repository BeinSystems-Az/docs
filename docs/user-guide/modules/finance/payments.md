# Ödəniş qeydə almaq

Ödəniş sənədi tərəfdaşla hesablaşma üzrə daxilolma və ya məxarici ERP-də qeyd edir. Bu qeyd bankdan faktiki köçürməni özü başlatmır.

## İstifadə qaydası

1. **Maliyyə → Ödənişlər** səhifəsini açın və **Yeni** seçin.
2. Ödəniş istiqamətini — daxilolma və ya məxaric — seçin. **Tərəfdaş**, **Hesab** və **Məbləğ** sahələrini doldurun.
3. Tarix, valyuta, ödəniş üsulu və sənəd izahı sahələrini formanın tələb etdiyi kimi daxil edin.
4. Faktura borcunu bağlayırsınızsa uyğun açıq hesablaşma sənədini seçin və bölüşdürülmüş məbləği yoxlayın.
5. Sənədi yadda saxlayıb tələb olunan **Təsdiq** əməliyyatını edin. Ödənişlər siyahısında statusu və hesab qalığını yoxlayın.

   > **Şəkil əlavə ediləcək —** `media/user-guide/finance/payments/images/screen-01.png`: Ödəniş istiqaməti, tərəfdaş, hesab və məbləğ sahələri.

## Lüğət

| Termin | Bu səhifədəki mənası |
| --- | --- |
| Daxilolma | Şirkətin pul hesabına pul daxil olmasıdır. |
| Məxaric | Şirkətin pul hesabından pul çıxmasıdır. |
| Tərəfdaş hesablaşması | Ödənişin müştəri və ya təchizatçı sənədinə bağlanmasıdır. |

## FAQ

### Ödəniş qeydi banka köçürmə əmri göndərir?

Xeyr. Bu səhifə ERP-də ödəniş qeydi yaradır; xarici bank əməliyyatını ayrıca icra edin.

### Ödəniş faktura borcunu niyə bağlamadı?

Ödənişin tərəfdaşını, istiqamətini, valyutasını və seçilmiş açıq hesablaşma sənədini yoxlayın.
