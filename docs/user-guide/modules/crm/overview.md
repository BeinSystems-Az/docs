# CRM ümumi baxışından istifadə etmək

CRM ümumi baxışı potensial müştərilərin vəziyyəti və CRM tapşırıqlarına bir ekrandan baxmağa kömək edir. Bu ekran lid yaratmaq və tapşırıq idarə etmək üçün uyğun CRM siyahılarına keçid verir.

## İstifadə qaydası

1. **CRM → Ümumi baxış** səhifəsini açın.
2. Görünən mərhələ və fəaliyyət göstəricilərini oxuyub gecikmiş və ya diqqət tələb edən qeydləri müəyyən edin.
3. Potensial müştəriyə baxmaq üçün **Lidlər**, məsul işi izləmək üçün **Tapşırıqlar** səhifəsinə keçin.
4. Göstərici ilə ilkin siyahı fərqlənirsə, eyni tarix/filtr əhatəsini tətbiq edin.

   > **Şəkil əlavə ediləcək —** `media/user-guide/crm/overview/images/screen-01.png`: CRM dashboard kartları və Lidlər/Tapşırıqlar keçidləri.

## Lüğət

| Termin | Bu səhifədəki mənası |
| --- | --- |
| Lid | Satış fürsəti ola biləcək ilkin əlaqə və ya müraciətdir. |
| Mərhələ | Lidin satış prosesindəki cari vəziyyətidir. |
| CRM fəaliyyət | Lid və ya müştəri ilə bağlı görülən işdir. |

## FAQ

### Ümumi baxışdan lidə keçmək olur?

Müvafiq göstərici və ya keçid varsa istifadə edin; tam siyahı və redaktə üçün **CRM → Lidlər** səhifəsini açın.

### Dashboard məlumatı yenilənmirsə nə edim?

Səhifəni yeniləyin, dövr filtrini yoxlayın və lid/tapşırıq siyahıları ilə tutuşdurun.
