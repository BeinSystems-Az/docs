# Lidi qeydiyyata almaq və izləmək

Lid potensial satış imkanını və onun növbəti addımlarını izləyir. Lid yaratmaq satış sənədi və ya gəlir qeydi yaratmır; uyğun mərhələdə satış sifarişi ayrıca başladılır.

## İstifadə qaydası

### Lidlər siyahısından başlayın

1. Sol menyudan **CRM → Lidlər** bölməsini açın. Satış mərhələlərinin ümumi vəziyyətini **CRM → Ümumi baxış** səhifəsində izləyin.

   > **Şəkil əlavə ediləcək —** `media/user-guide/crm/leads/images/screen-01.png`: CRM menyusunda Lidlər və Ümumi baxış; lid siyahısının əsas sütunları.

2. **Yeni** düyməsini seçin. **Lidin adı**, **Satış prosesi**, **Mərhələ**, **Tərəf-müqabil** və **Filial** sahələrini doldurun. Mərhələ seçimi seçilmiş satış prosesinə uyğun olmalıdır.

### Müraciəti qiymətləndirin və sahibi təyin edin

3. **Məsul istifadəçi** sahəsində lid üzərində işləyəcək şəxsi seçin. **Mənbə** ilə müraciətin haradan gəldiyini qeyd edin.

4. Məbləğ ehtimalı qiymətləndirilə bilirsə **Gözlənilən satış məbləği**, **Valyuta**, **Uğur ehtimalı (%)** və **Gözlənilən bağlanma tarixi** məlumatlarını daxil edin. **Tələbat və qeydlər** sahəsində müştərinin ehtiyacını və razılaşdırılan növbəti addımı yazın.

   > **Şəkil əlavə ediləcək —** `media/user-guide/crm/leads/images/screen-02.png`: Lid kartında ad, proses/mərhələ, tərəf-müqabil və məsul istifadəçi sahələri.

5. Kartı yadda saxlayın. Lid dəyişdikcə mərhələni yeniləyin və əlaqəli tapşırıqları lid kartından yaradın.

### Satış imkanını növbəti sənədə keçirin

6. Müştəri satışa hazır olduqda lid kartında **Yarat → Satış təklifi** əməliyyatını seçin. Yaradılan sifarişdə müştəri və CRM lid əlaqəsini yoxlayın.

   > **Video əlavə ediləcək —** `media/user-guide/crm/leads/videos/walkthrough-01.mp4`: Lid yaratmaq, mərhələ/məsul təyin etmək və lid kartından satış sifarişi başlatmaq.

## Lüğət

| Termin | Bu səhifədəki mənası |
| --- | --- |
| Lid | Hələ satış sifarişinə çevrilməmiş potensial satış müraciətidir. |
| Satış prosesi | Lidlərin keçdiyi mərhələlər toplusudur. |
| Mərhələ | Lid ilə işin hazırkı vəziyyətini satış prosesi daxilində göstərir. |
| Uğur ehtimalı | Lidin satışa çevrilmə ehtimalı üzrə daxil edilən qiymətləndirmədir. |

## FAQ

### Lid yaratmaq satış sifarişi yaradırmı?

Xeyr. Satışa keçmək qərarı verildikdə lid kartındakı **Yarat → Satış təklifi** əməliyyatından başlayın.

### Mərhələ niyə seçilmir?

Əvvəlcə **Satış prosesi** seçin. Mərhələlər prosesə bağlı olduğundan başqa prosesin mərhələsi burada uyğun olmaya bilər.

### Lid üçün məsul istifadəçi göstərmək vacibdirmi?

Məsul təyin etmək işin kim tərəfindən izlənəcəyini aydınlaşdırır. Komandanızın iş qaydasına uyğun istifadəçi seçin.
