# Layihələri idarə etmək

Layihə qeydi əlaqəli işləri və sənədləri ümumi ad və kod altında izləmək üçündür. Siyahı və forma standart sistem resursu kimi işləyir.

## İstifadə qaydası

### Layihə yaradın

1. **Şirkətim → Layihələr** bölməsini açın və **Yeni** əməliyyatını başladın.
2. **Layihə adı** sahəsinə tanınan ad, **Kod** sahəsinə isə unikal qısa kod daxil edin. Hər iki sahə tələb olunur.
3. Lazımdırsa təsviri yazın və layihənin aktiv olub-olmadığını seçin.
4. Formanı yadda saxlayın. Layihənin siyahıda göründüyünü və ad/kodun düzgün olduğunu yoxlayın.

   > **Şəkil əlavə ediləcək —** `media/user-guide/operations/projects/images/screen-01.png`: Layihə adı, kod, təsvir və aktivlik sahələri.

### Layihəni dəyişin və sənədlərdə istifadə edin

5. Siyahıdan layihəni açın, ad, təsvir və aktivlik məlumatını yeniləyib yadda saxlayın.
6. Layihə seçimi təqdim edən sənədlərdə uyğun layihəni qeyd edin. Layihə seçimi həmin sənəd formasında yoxdursa, onu ayrıca sahə kimi daxil etməyin.

   > **Video əlavə ediləcək —** `media/user-guide/operations/projects/videos/walkthrough-01.mp4`: Layihə yaratmaq və dəstəkləyən sənəddə layihəni seçmək.

## Lüğət

| Layihə adı | Siyahılarda görünən layihə başlığıdır. |

## FAQ

### Layihə yaratmaq üçün hansı sahələr məcburidir?

Layihə adı və kod tələb olunur. Təsvir və aktivlik əlavə məlumatlardır.

### Layihə kodunu başqa layihədə də istifadə edə bilərəm?

Layihələri ayırd etmək üçün kodu unikal saxlayın. Eyni kod qəbul edilmirsə, layihəyə fərqli kod verin.
