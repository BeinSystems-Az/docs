# Audit tarixçəsini yoxlamaq

Audit səhifəsi sistemdə qeydə alınmış istifadəçi hərəkətlərini, nəticəni və mövcud olduqda dəyişiklik detallarını araşdırmağa kömək edir.

## İstifadə qaydası

### Hadisələri tapın

1. **Şirkətim → Audit** bölməsini açın.
2. Siyahıda istifadəçi, vaxt, hadisə və nəticə məlumatlarına baxın.
3. Axtarış və filtrlər görünürsə, istifadəçi, tarix və hadisə növü üzrə daraldın.

### Dəyişiklik detalını yoxlayın

4. Araşdırdığınız sətri açın.
5. Hadisənin obyektini, əvvəlki və yeni dəyərləri, nəticə mesajını və əlaqəli identifikatorları yoxlayın.
6. Düzəliş tələb olunursa, həmin obyektin öz moduluna keçin. Audit ekranı tarixçə üçündür.

   > **Şəkil əlavə ediləcək —** `media/user-guide/operations/audit/images/screen-01.png`: Filtrlər, hadisə sətri və dəyişiklik detalları.

   > **Video əlavə ediləcək —** `media/user-guide/operations/audit/videos/walkthrough-01.mp4`: Tarix/istifadəçi üzrə axtarış və hadisə detalının açılması.

## Lüğət

| Termin | Bu səhifədəki mənası |
| --- | --- |
| Hadisə | Audit tarixçəsində saxlanmış istifadəçi və ya sistem hərəkətidir. |
| Obyekt | Hadisənin aid olduğu sənəd və ya məlumat qeydidir. |
| Əvvəlki dəyər | Dəyişiklikdən qabaq qeydə alınmış məlumatdır. |
| Yeni dəyər | Dəyişiklikdən sonra qeydə alınmış məlumatdır. |

## FAQ

### Hər ekran əməliyyatı Audit-də görünür?

Yalnız sistemin auditə yazdığı hadisələr görünür. Hər klik və baxışın qeydə alınacağına zəmanət yoxdur.

### Audit qeydini buradan silmək və ya dəyişmək olar?

Audit səhifəsi tarixçə və yoxlama üçündür. Hadisənin özünü redaktə etmək üçün əməliyyat təqdim edilmir.
