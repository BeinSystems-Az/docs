# Göstəricilərə baxış

Göstəricilər səhifəsi şirkətin əsas əməliyyat nəticələrini bir yerdə izləməyə kömək edir. Kart və qrafiklər istifadəçinin icazəsinə, seçilmiş dövrə və tenantda mövcud məlumatlara uyğun görünür.

## İstifadə qaydası

### Göstəricilər səhifəsini açın

1. Sol menyudan **Şirkətim → Göstəricilər** bölməsinə keçin.
2. Ekrandakı dövr və digər filtrləri seçərək nəticələri ehtiyacınıza uyğunlaşdırın.
3. Kartlarda göstərilən say və məbləğləri aşağıdakı qrafik və siyahılarla tutuşdurun.

   > **Şəkil əlavə ediləcək —** `media/user-guide/operations/dashboard/images/screen-01.png`: Göstəricilər səhifəsinin əsas kartları və dövr filtri.

### Göstəricidən ilkin sənədə keçin

4. Fərq və ya gözlənilməyən nəticə gördükdə həmin göstəricinin izahına və əlaqəli siyahı səhifəsinə keçin.
5. İlkin sənədi öz modulunda açıb tarix, filial, status və məbləğ filtrləri ilə araşdırın. Göstərici kartını ilkin sənədin əvəzi kimi istifadə etməyin.

   > **Video əlavə ediləcək —** `media/user-guide/operations/dashboard/videos/walkthrough-01.mp4`: Ümumi göstəricidən əlaqəli əməliyyat siyahısına keçid və filtr tətbiqi.

## Lüğət

| Termin | Bu səhifədəki mənası |
| --- | --- |
| Göstərici | Əməliyyat məlumatlarından hesablanan say, məbləğ və ya nisbətdir. |
| Dövr | Nəticələrin hesablanması üçün seçilən tarix aralığıdır. |
| İlkin sənəd | Göstəricidəki nəticəni yaradan faktura, sifariş, ödəniş və ya başqa əməliyyat qeydidir. |

## FAQ

### Göstərici niyə boş görünür?

Seçilmiş dövrdə məlumat olmaya, istifadəçi icazəsi çatmaya və ya müvafiq modul aktiv olmaya bilər. Tarix filtrini və ilkin modul siyahısını yoxlayın.

### Paneldəki məbləğlə hesabatdakı məbləğ fərqlənə bilər?

Bəli. Dövr, filial, status və hesaba daxil edilən sənəd növləri fərqli ola bilər. Müqayisədə eyni filtrləri və eyni hesablama əhatəsini seçin.
