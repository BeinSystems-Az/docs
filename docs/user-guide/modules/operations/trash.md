# Səbətdəki qeydləri bərpa etmək

Səbət ERP-dən silinmiş qeydləri növünə görə tapmağa və seçilmiş qeydləri bərpa etməyə imkan verir. Buradakı siyahı aktiv məhsul və sənəd siyahısı deyil.

## İstifadə qaydası

### Silinmiş qeydi tapın

1. **Şirkətim → Səbət** səhifəsini açın.
2. Siyahıda qeydin növünü, adını, silinmə tarixini və varsa tərəfdaş, anbar, şirkət və məbləğ məlumatlarını yoxlayın.
3. **Filtrlər** bölməsində **Məlumat növü** seçərək siyahını daraldın. Axtarışdan qeydin adını tapmaq üçün istifadə edin.
4. Sətri açaraq silinmiş qeydin təfərrüatına baxın. Bərpa edəcəyiniz qeydin düzgün şirkətə və qeyd növünə aid olduğunu yoxlayın.

   > **Şəkil əlavə ediləcək —** `media/user-guide/operations/trash/images/screen-01.png`: Səbətdə məlumat növü filtri, silinmiş qeydlərin siyahısı və açılmış bir qeyd.

### Qeydi bərpa edin

5. Bərpa olunacaq sətirləri seçin. Bir neçə qeydi birlikdə seçdikdə siyahının aşağısında **Bərpa et** əməliyyatı görünür.
6. **Bərpa et** seçin və nəticə bildirişini yoxlayın. Uğurlu və uğursuz bərpalar ayrıca sayla göstərilə bilər.
7. Bərpa edilmiş qeydin ilkin modul siyahısında göründüyünü yoxlayın. Səbətdə qalması davam edirsə, qeyd bərpa olunmayıb və ya istifadəçi icazəsi məhdud ola bilər.

   > **Video əlavə ediləcək —** `media/user-guide/operations/trash/videos/walkthrough-01.mp4`: Səbətdə məlumat növünə görə axtarış, qeydin seçilməsi, bərpa və ilkin siyahıda nəticənin yoxlanması.

## Lüğət

| Termin | Bu səhifədəki mənası |
| --- | --- |
| Silinmiş qeyd | İlkin siyahıdan silinib, lakin bərpa üçün səbətdə saxlanılan qeyddir. |
| Bərpa | Silinmiş qeydi yenidən ilkin modulda əlçatan edən əməliyyatdır. |
| Məlumat növü | Səbətdəki qeydin hansı resursa, məsələn məhsula və ya sənədə aid olduğunu bildirir. |

## FAQ

### Səbət qeydi birdəfəlik silir?

Bu səhifədə sənədləşdirilmiş siyahı seçilmiş qeydləri bərpa etməyə imkan verir. Siyahıda birdəfəlik silmə əməliyyatı göstərilmir.

### Bərpa etdiyim qeyd niyə əvvəlki siyahıda görünmür?

İlkin modulu yeniləyin, uyğun məlumat növü və filtr seçildiyini yoxlayın. Qeydin görünməsi üçün həmin resursa oxuma icazəsi də tələb oluna bilər.

### Bərpa bildirişində uğursuz qeyd görünürsə nə etməliyəm?

Bildirişdəki uğurlu və uğursuz sayları yoxlayın, qeydin detalını açın və icazə və ya məlumat məhdudiyyətini administratorla araşdırın.
