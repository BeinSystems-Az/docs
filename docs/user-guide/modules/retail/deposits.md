# POS mədaxilini yoxlamaq

**Pərakəndə → Mədaxil** səhifəsi POS kassasına satışdan kənar daxil edilən nağd pul hərəkətlərini göstərir.

## İstifadə qaydası

1. **Pərakəndə → Mədaxil** siyahısını açın.
2. Tarix, kassa və səbəb üzrə qeydi tapın, məbləğ və qeydi yoxlayın.
3. Əlaqəli POS növbəsini açıb hesabatda həmin mədaxilin əks olunduğunu yoxlayın.
4. Məbləğ və ya səbəb yanlışdırsa, ilkin əməliyyatı POS terminalında düzəldin və sync statusunu yoxlayın.

   > **Şəkil əlavə ediləcək —** `media/user-guide/retail/deposits/images/screen-01.png`: Kassa, səbəb, tarix və məbləğ sütunları.

## Lüğət

| Termin | Bu səhifədəki mənası |
| --- | --- |
| Mədaxil | Kassaya satışdan ayrıca əlavə edilmiş nağd vəsaitdir. |
| Kassa səbəbi | Mədaxilin hansı məqsədlə edildiyini göstərən seçimdir. |

## FAQ

### Mədaxil qeydi satış məbləğini artırır?

Xeyr. Bu, ayrıca kassa pul hərəkətidir; POS satış hesabatından ayrıca yoxlayın.

### Mədaxil məlumatını ERP-də redaktə edə bilərəm?

Sinxronizasiya olunmuş POS əməliyyat siyahısı yalnız oxunur; düzəlişi POS terminalında edin.
