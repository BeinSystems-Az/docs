# POS məxaricini yoxlamaq

**Pərakəndə → Məxaric** səhifəsi POS kassasından çıxarılan, satışdan ayrı nağd pul hərəkətlərini göstərir.

## İstifadə qaydası

1. **Pərakəndə → Məxaric** siyahısını açıb tarix, kassa və səbəb üzrə qeydi tapın.
2. Məbləği, səbəbi, vaxtı və qeydi qəbz/kassa sənədləri ilə tutuşdurun.
3. POS növbəsi hesabatında məxaricin yekun nağd hesablamasına daxil olduğunu yoxlayın.
4. Xəta varsa düzəlişi POS terminalında edin və **Sync** monitorunda ötürülmə vəziyyətini yoxlayın.

   > **Şəkil əlavə ediləcək —** `media/user-guide/retail/withdrawals/images/screen-01.png`: Məxaric siyahısında kassa, səbəb və məbləğ.

## Lüğət

| Termin | Bu səhifədəki mənası |
| --- | --- |
| Məxaric | Kassadan satışdan ayrıca çıxarılan pul məbləğidir. |
| Kassa səbəbi | Məxaricin məqsədini və uçot istiqamətini bildirən seçimdir. |

## FAQ

### Məxaric qeydi POS satışını azaldır?

Xeyr. Bu, kassa nağd qalığına aid ayrıca hərəkətdir; satış cəmini dəyişmir.

### Məxaric siyahısında düzəliş edə bilərəm?

Sinxronizasiya olunmuş qeyd ERP-də yalnız oxunur. Düzəlişi POS terminalında aparın.
