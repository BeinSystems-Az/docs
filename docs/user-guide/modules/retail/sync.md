# POS sinxronizasiyasını yoxlamaq

**Pərakəndə → Sync** səhifəsi aktiv POS kassalarını, gözləyən əməliyyatları və açıq problemləri izləmək üçündür.

## İstifadə qaydası

1. **Pərakəndə → Sync** səhifəsini açın və **Yenilə** düyməsini seçin.
2. Aktiv kassaların vəziyyətini, ötürülməyən əməliyyatların sayını və açıq problem siyahısını nəzərdən keçirin.
3. Problem sətrini açıb kassa, vaxt, əməliyyat növü və xəta mesajını yoxlayın.
4. POS cihazının bağlantısını və əməliyyatın terminalda düzgün qeydə alındığını təsdiqləyin; lazım gələrsə terminalın sinxronizasiya prosesini yenidən başladın.
5. Monitoru yeniləyib həmin əməliyyatın gözləyən siyahıdan çıxdığını yoxlayın.

   > **Şəkil əlavə ediləcək —** `media/user-guide/retail/sync/images/screen-01.png`: Aktiv kassalar, gözləyən əməliyyat sayı və xəta detalları.

## Lüğət

| Termin | Bu səhifədəki mənası |
| --- | --- |
| Gözləyən əməliyyat | POS-da yaradılıb ERP-yə hələ çatdırılmamış qeyddir. |
| Açıq problem | Sinxronizasiya prosesində həll edilməmiş xəta və ya xəbərdarlıqdır. |
| Aktiv kassa | ERP ilə əlaqəsi işlək görünən POS kassasıdır. |

## FAQ

### Gözləyən əməliyyat niyə artmır?

POS cihazı və şəbəkə bağlantısını yoxlayıb səhifədə **Yenilə** seçin.

### Xəta qeydini ERP-dən düzəldə bilərəm?

Əməliyyatın ilkin mənbəyini və xəta mesajını araşdırın. POS məlumatına aid düzəliş terminalda edilməlidir.
