# POS qaytarmasını yoxlamaq

**Pərakəndə → Qaytarmalar** səhifəsində POS terminalından sinxronizasiya olunan qaytarmalar göstərilir. Qaytarma qeydi mənbə POS satış qəbzi ilə tutuşdurulmalıdır.

## İstifadə qaydası

1. **Pərakəndə → Qaytarmalar** siyahısını açıb qəbz, kassa və tarix üzrə qaytarmanı tapın.
2. Sətri açıb **Mənbə satış**, qaytarılmış məhsul/miqdarı, məbləği və statusu yoxlayın.
3. Qaytarma qəbzini POS məlumatı ilə tutuşdurun. Qeyd səhvidirsə düzəlişi POS terminalında aparın.
4. Qaytarma anbara necə təsir etdiyini **Anbar qalığı** hesabatında yoxlayın.

   > **Şəkil əlavə ediləcək —** `media/user-guide/retail/pos-returns/images/screen-01.png`: POS qaytarmasında mənbə satış, məhsul, məbləğ və status.

## Lüğət

| Termin | Bu səhifədəki mənası |
| --- | --- |
| Mənbə satış | Qaytarma üçün əsas götürülən ilkin POS qəbzidir. |
| Qaytarma | Satılmış məhsulun və ya məbləğin POS-da qaytarılması barədə qeyddir. |

## FAQ

### Qaytarmanı ERP səhifəsindən yaratmaq olar?

POS qaytarmaları terminaldan sinxronizasiya olunan və ERP-də yalnız oxunan qeydlərdir. Qaytarmanı POS terminalında yaradın.

### Qaytarma stok qalığını dəyişmirsə nəyi yoxlamalıyam?

POS sinxronizasiya statusunu, qaytarmanın bağlı olduğu ilkin satışı və yenilənmiş stok hesabatını yoxlayın.
