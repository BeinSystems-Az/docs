# POS növbəsini yoxlamaq

**Pərakəndə → Növbələr** siyahısı POS cihazlarından sinxronizasiya olunmuş növbələri və növbə hesabatını göstərir. Növbə siyahısı ERP-də yalnız oxunur.

## İstifadə qaydası

1. **Pərakəndə → Növbələr** səhifəsini açın və kassa, filial, tarix və status üzrə lazım olan növbəni tapın.
2. Növbə sətrini seçib **Növbə hesabatı** panelini açın.
3. Açılış/bağlanış vaxtı və kassiri, satış/qaytarma məbləğlərini, mədaxil/məxaric və sayılmış nağdı tutuşdurun.
4. Fərq varsa **Sync** səhifəsində əlaqəli sinxronizasiya problem və əməliyyatlarını yoxlayın.

   > **Şəkil əlavə ediləcək —** `media/user-guide/retail/shifts/images/screen-01.png`: Növbə hesabatında kassa, satış, qaytarma və pul hərəkətləri.

## Lüğət

| Termin | Bu səhifədəki mənası |
| --- | --- |
| Növbə | Kassirin POS cihazında açdığı və bağladığı iş sessiyasıdır. |
| Sayılmış nağd | Növbə bağlanarkən kassada fiziki sayılan puldur. |
| Z-hesabat | POS növbəsinin yekun satış və nağd göstəriciləridir. |

## FAQ

### Növbəni ERP-dən bağlaya bilərəm?

Xeyr. ERP-dəki növbə və hesabat görünüşü yalnız oxunur; növbə əməliyyatını POS cihazında aparın.

### Növbədə məbləğ fərqi görünür?

POS, ERP, sayılmış nağd və həmin növbənin mədaxil/məxaric qeydlərini tutuşdurun.
