# Kassa səbəbi yaratmaq

Kassa səbəbi POS-da satışdan ayrıca mədaxil və məxaricin məqsədini müəyyən edir. İstiqamət və uçot hesabı əməliyyat siyahılarında düzgün təsnifat üçün istifadə olunur.

## İstifadə qaydası

1. **Pərakəndə → Kassa səbəbləri** səhifəsini açıb **Yeni** seçin.
2. Səbəbin **Kod** və **Ad**ını daxil edin.
3. **İstiqamət** sahəsində **Mədaxil**, **Məxaric** və ya **Hər ikisi** seçin.
4. **Uçot hesabı** seçib səbəbi yadda saxlayın.
5. POS kassa əməliyyatında yeni səbəbin uyğun istiqamətdə çıxdığını yoxlayın.

   > **Şəkil əlavə ediləcək —** `media/user-guide/retail/reasons/images/screen-01.png`: Kod/ad, istiqamət və uçot hesabı sahələri.

## Lüğət

| Termin | Bu səhifədəki mənası |
| --- | --- |
| İstiqamət | Səbəbin mədaxil, məxaric və ya hər iki əməliyyatda istifadə olunacağını bildirir. |
| Uçot hesabı | Kassa hərəkətinin maliyyə uçotunda bağlandığı hesabdır. |

## FAQ

### Səbəb yalnız mədaxil üçündürsə hansı istiqaməti seçməliyəm?

**Mədaxil** seçin; məxaric əməliyyatında həmin səbəb göstərilməməlidir.

### Səbəbin adını dəyişmək POS-da dərhal görünür?

Siyahını yadda saxladıqdan sonra POS-un yenilənmiş konfiqurasiya almasını yoxlayın.
