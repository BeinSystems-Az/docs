# POS satış qəbzini yoxlamaq

**Pərakəndə → Satışlar** POS-da yaranıb ERP-yə sinxronizasiya olunan satış qəbzlərini göstərir. Siyahı və satış detalları ERP-dən redaktə edilmir.

## İstifadə qaydası

1. **Pərakəndə → Satışlar** səhifəsini açıb tarix, kassa, anbar, müştəri və status filtrləri ilə qəbzi tapın.
2. Qəbzi açın və məhsul sətirlərini, miqdarı, qiymət/vergi hesablamasını tutuşdurun.
3. Ödəniş növlərini və məbləğləri POS qəbzi ilə müqayisə edin.
4. Səhv məlumat aşkar edilərsə düzəlişi POS-da edin, sonra sinxronizasiyanın tamamlandığını ERP siyahısından yoxlayın.

   > **Şəkil əlavə ediləcək —** `media/user-guide/retail/pos-sales/images/screen-01.png`: POS satış siyahısı və açılmış qəbzdə məhsul/ödəniş detalları.

## Lüğət

| Termin | Bu səhifədəki mənası |
| --- | --- |
| POS qəbzi | Pərakəndə satış terminalında yaradılan satış qeydidir. |
| Sinxronizasiya | POS satış məlumatının ERP-yə ötürülməsidir. |
| Ödəniş bölgüsü | Qəbz məbləğinin nağd, kart və digər üsullar üzrə bölünməsidir. |

## FAQ

### POS satışını ERP siyahısından redaktə etmək olar?

Xeyr. Dəyişiklik POS terminalında aparılmalı və sinxronizasiya yoxlanmalıdır.

### Qəbz ERP-də görünmür?

**Pərakəndə → Sync** səhifəsində kassa, gözləyən əməliyyat və xəta məlumatını yoxlayın.
