# Sənədi təsdiq etmək və ya rədd etmək

**Şirkətim → Mənim təsdiqlərim** səhifəsində istifadəçiyə yönləndirilmiş sənəd qərarları göstərilir. Qərar verməzdən əvvəl təsdiq tapşırığındakı sənəd məlumatını və sənədin özünü yoxlayın.

## İstifadə qaydası

1. **Mənim təsdiqlərim** səhifəsini açıb qərar gözləyən sətri tapın.
2. **Bax və qərar ver** düyməsini seçin. Pəncərədə proses adını, sənəd növünü/nömrəsini və tələb olunan təsdiq sayını yoxlayın.
3. Sənədi müvafiq modulda ayrıca açıb məzmunu, məbləği və əlaqəli məlumatları nəzərdən keçirin.
4. Təsdiq edirsinizsə **Təsdiqlə** seçin. Rədd edirsinizsə **Qeyd** sahəsinə səbəbi yazın və **Rədd et** düyməsini seçin.
5. Qərar göndərildikdən sonra tapşırığın növbədən çıxdığını və sənədin cari statusunu yoxlayın.

   > **Şəkil əlavə ediləcək —** `media/user-guide/automation/approvals/images/screen-01.png`: Qərar gözləyən tapşırıq, sənəd identifikasiyası, qeyd və təsdiq/rədd düymələri.

## Lüğət

| Termin | Bu səhifədəki mənası |
| --- | --- |
| Təsdiq tapşırığı | Workflow çərçivəsində istifadəçidən gözlənilən sənəd qərarıdır. |
| Təsdiq sayı | Prosesin davam etməsi üçün lazım olan qərar sayıdır. |
| Rədd qeydi | Sənədin niyə rədd edildiyini izah edən məcburi şərhdir. |

## FAQ

### Rədd səbəbini yazmadan göndərə bilərəm?

Xeyr. **Rədd et** əməliyyatı üçün **Qeyd** sahəsi boş olmamalıdır.

### Təsdiqlədikdən sonra sənəd dərhal tamamlanır?

Bu, workflow-un tələb etdiyi təsdiq sayından və sonrakı addımlarından asılıdır. Sənəd statusunu ayrıca yoxlayın.
