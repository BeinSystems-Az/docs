# Şirkətlərarası sənədlərlə işləmək

Şirkətlərarası şəbəkə tenantlar arasında bağlantı qurmağa və dəstəklənən sənədləri mübadilə etməyə imkan verir. Qarşı tərəfdən qəbul edilən sənəd yerli sistemdə qaralama kimi yaradılır; yoxlamadan sonra onu öz biznes prosesinizdə davam etdirin.

## İstifadə qaydası

### Şirkətlə bağlantı qurun

1. **Şirkətim → Şirkətlərarası şəbəkə** bölməsini açın.
2. **Əlaqələr** tabında, idarəetmə icazəniz varsa, qarşı tərəfin tenant adını axtarın.
3. Tapılan şirkəti yoxlayıb **Dəvət göndər** əməliyyatını başladın. Qarşı tərəfin qərarını əlaqələr siyahısından izləyin.

### Daxil olan sənədə baxın

4. **Gələnlər** tabında gözləyən sənədi tapın; şirkət, sənəd növü, status və tarix filtrlərindən istifadə edin.
5. Sənədi açıb sətirləri və sahə uyğunluğunu yoxlayın. Qəbul etmək sənədi ERP-də qaralama kimi yaradır.
6. Yaradılmış qaralamanı müvafiq modulda açın, məlumatları yoxlayın və təşkilatın qaydasına uyğun davam etdirin.

### Göndəriş və mapping-i izləyin

7. Öz göndərişlərə baxmaq üçün **Göndərilənlər** tabına keçib status filtrini tətbiq edin.
8. **Mapping-lər** tabında tərəfdaşla məhsul və digər uyğunlaşdırmaları yoxlayın. Uyğunluq xətası varsa, göndərişi təkrar etməzdən əvvəl mapping-i düzəldin.

## Lüğət

| Termin | Bu səhifədəki mənası |
| --- | --- |
| Tenant adı | Şəbəkədə şirkəti tapmaq və tanımaq üçün istifadə olunan hesab adıdır. |
| Gələn sənəd | Başqa şirkətdən bu tenant-a göndərilmiş sənəddir. |
| Mapping | Tərəflərin məhsul və sahə dəyərləri arasındakı uyğunlaşdırmadır. |
| Qaralama | Qəbuldan sonra yaranan, hələ yekun əməliyyat edilməmiş sənəddir. |

## FAQ

### Sənədi qəbul etmək onu avtomatik təsdiqləyir?

Xeyr. Qəbul sənədi yerli sistemdə qaralama yaradır. Sənədi yoxlayıb normal modul axını ilə işləmək lazımdır.

### Sənəd niyə mapping xətası alır?

Qarşı tərəfin məhsulu və ya sahə dəyəri yerli qeydlə uyğun gəlməyə bilər. **Mapping-lər** tabında uyğunluğu yaradın və ya yeniləyin.
