# Workflow icrasını izləmək

**Şirkətim → Avtomatlaşdırma** səhifəsində workflow qaydalarının aktivliyi, icra tarixçəsi və xətaları izlənir. Workflow hadisə, şərt və addımları avtomatik icra edir.

## İstifadə qaydası

1. **Workflow-lar** tabında qaydanın adını, başladan hadisəni, şərt/addım sayını və aktivliyini yoxlayın.
2. Qaydanı dəyişmək üçün onun redaktə əməliyyatını açın; istifadədə olan qaydanı söndürməzdən əvvəl ona bağlı biznes prosesini nəzərdən keçirin.
3. **İcra tarixçəsi** tabını açıb status filtrindən istifadə edərək uğursuz və ya tamamlanmış icranı tapın.
4. İcranın **Detallar** pəncərəsində xəta və cəhd məlumatını oxuyun.
5. Xəta səbəbini aradan qaldırdıqdan sonra icazəniz və status uyğundursa **Təkrar et** seçin.

   > **Şəkil əlavə ediləcək —** `media/user-guide/automation/workflows/images/screen-01.png`: Workflow siyahısı, status filtri və icra detalı.

## Lüğət

| Termin | Bu səhifədəki mənası |
| --- | --- |
| Workflow | Hadisəyə cavab olaraq şərt və addımları icra edən qaydadır. |
| İcra tarixçəsi | Workflow cəhdlərinin nəticələrini göstərən siyahıdır. |
| Təkrar icra | Uğursuz workflow cəhdini səbəb aradan qaldırıldıqdan sonra yenidən başlatmaqdır. |

## FAQ

### Workflow xətası ilkin sənədi avtomatik ləğv edir?

İcra xətası workflow cəhdinin statusudur. İlkin sənədin statusunu onun öz ekranında ayrıca yoxlayın.

### Hər uğursuz icranı təkrar başlatmaq olar?

Xeyr. Təkrar əməliyyatı yalnız uyğun icra statusu və istifadəçi icazəsi olduqda görünür.
