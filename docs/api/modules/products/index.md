# Məhsul kataloqu

Məhsullar modulu məhsul kartı, şablon, kateqoriya, vahid, qablaşdırma və atributları idarə edir. Bu resurslar master data-dır: yaratmaq, yeniləmək və silmək fiziki stok, rezervasiya və ya jurnal entry yaratmır.

## Resurslar

- [Məhsullar](/docs/api/catalog/products)
- [Məhsul şablonları](/docs/api/catalog/product-templates)
- [Kateqoriyalar](/docs/api/catalog/categories)
- [Ölçü vahidləri](/docs/api/catalog/units)
- [Qablaşdırmalar](/docs/api/catalog/product-packagings)
- [Atributlar](/docs/api/catalog/product-attributes)

Məhsul sonradan satış, alış və anbar sənədinə daxil ediləndə onun qiymət, vergi, vahid və hesab sazlamaları həmin sənədin hesablamasına təsir edir.
